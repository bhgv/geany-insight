# Скриптование Geany Insight

В настольном редакторе встроен Lua 5.4.8. Расширения регистрируют команды, назначают сочетания клавиш и подписываются на события. Для выполнения редакторских команд не нужно устанавливать внешний Lua.

## Первое расширение

Создайте и сохраните UTF-8 файл `my-commands.lua`:

```lua
commands.register("selection.wrap", "Обрамить выделение", function()
    if not editor.has("replace_selection") then
        editor.message("Документ недоступен для редактирования")
        return
    end
    editor.replace_selection("(" .. editor.selection() .. ")")
end, "<Primary><Alt>w")
```

Откройте Scripts → Load extension… и выберите файл. В редакторе выделите слово и нажмите Ctrl+Alt+W. Выделение превратится в `(слово)`. Команда доступна также в Scripts → Commands и палитре Ctrl+Shift+P. Ctrl+Z отменяет правку.

Primary означает основной модификатор платформы. Проверьте возможные конфликты горячих клавиш с Geany и плагинами. При конфликте вызовите команду через меню.

## Загрузка, повторный запуск и состояние

Scripts → Run script… выполняет файл один раз в новом Lua-состоянии. Регистрируемые команды храните в расширении, а разовые правки — в одноразовом скрипте. Scripts → Reload saved extension перечитывает расширение с диска; предварительно сохраните его. Unload extension выключает расширение и его автозагрузку.

Путь загруженного расширения запоминается. При следующем запуске регистрируются команды и обработчики. Во время загрузки не обращайтесь к текущему документу: используйте editor и project внутри callback команды. Переменные и замыкания сохраняются между вызовами до перезагрузки расширения или редактора.

## Работа с текстом

```lua
commands.register("line.describe", "Показать позицию", function()
    local begin, finish = editor.selection_range()
    editor.message("Выделение: " .. begin .. " .. " .. finish)
end)
```

Позиции — байтовые смещения UTF-8 с нуля; конец диапазона не включается. Номер строки — с единицы. Кириллица занимает несколько байт: не считайте длину по визуальному числу букв. `editor.set_selection`, `replace_range` и `insert` проверяют границы UTF-8.

`editor.text()` возвращает текст, `selection()` — выделение, `replace_selection(text)` — заменяет его. `filename()` возвращает путь или nil для несохранённого буфера. `goto_line(n)` переходит к строке. `save()` сохраняет именованный документ; безымянный сначала сохраните через интерфейс.

Один вызов команды объединяет свои изменения в Undo. Ошибка не откатывает уже выполненные изменения — используйте Undo и исправьте скрипт. Не выполняйте долговременную работу в callback: команды работают в потоке интерфейса.

## События и поиск по индексу

Полный синтаксис `events.on`, доступные названия событий и `project.query` смотрите в [Lua API 0.8](lua-api.md). Документные события предназначены для наблюдения: изменения документа внутри такого обработчика запрещены. События, возникшие во время исполнения другой Lua-команды, пропускаются, чтобы не создавать рекурсию.

`editor.has(name)` проверяет возможности текущего host и состояние документа. Строка `INSIGHT_API_VERSION` сейчас равна `"0.8"`; не делайте вывод о наличии конкретного метода только по версии.

## Ограничения и ошибки

Доступ к io, os, package и debug отключён. Модули из внешних файлов пока не загружаются. На расширение выделено 16 MiB Lua-памяти; вызовы имеют бюджет инструкций. Файл расширения ограничен 256 KiB. Это ограничения встроенного runtime, а не обещание строгой изоляции C-host.

Ошибки Lua сообщаются с traceback. Проверьте строку ошибки, сохраните исправленный файл и выберите Reload saved extension. При неудачной загрузке прежнее работающее расширение сохраняется.

[Справочник API и точные ограничения](lua-api.md), [практические уроки](tutorials.md), [руководство пользователя](guide.md).

Готовый `workbench.lua` установлен рядом со справкой: `../examples/workbench.lua` относительно каталога `insight/docs`. В Windows portable-комплекте примеры также находятся в `examples` в корне архива. Загрузите файл через Scripts → Load extension…: он регистрирует вывод символов файла, переход к следующему употреблению выделенного имени и сообщение о сохранении.
