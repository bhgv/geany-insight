# Типы файлов

Файлы проекта, сгруппированные по расширениям.

## Управление

Раскрытие группы показывает файлы данного расширения. Привязка языка задаётся отдельно: Options → языки или правой кнопкой в редакторе.

## Короткий урок

Найдите группу заголовочных файлов, раскройте её и откройте нужный файл двойным щелчком.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [languages.md](languages.md).
