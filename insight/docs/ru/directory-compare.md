# Сравнение каталогов

Откройте **Инструменты → Сравнение каталогов…** или **Сравнить каталоги…** в File
Compare. Выберите два каталога и нажмите **Сканировать / Обновить**, Enter в пути
или F5. Обход и чтение работают в отменяемом GTask-потоке; строки GTK готовятся
idle-порциями примерно по 3 мс. Отмена, ошибка обхода, неверный корень и лимит
сохраняют прежний снимок. Поздний ответ не обновляет уничтоженное окно.

## Методы и параметры

| Метод | Что означает «Одинаковые» для файлов |
| --- | --- |
| По содержимому | Совпадают байты; даты не влияют |
| По датам изменения | Совпадает время с микросекундами; размер и содержимое не читаются |
| По размерам и датам | Совпадают размер и время; содержимое не читается |

**Включать подкаталоги** разрешает рекурсивный обход; без него сравниваются прямые
потомки. **Включать скрытые элементы** включает имена с точкой и атрибут hidden.
Параметры применяются следующим сканированием. Наблюдения за файловой системой
нет: обновляйте F5. Сопоставляются точные относительные пути с учётом регистра,
даже на нечувствительных к регистру ФС. Корни должны представляться в кодировке
интерфейса; имена потомков хранятся в исходной кодировке и имеют отображаемые имена.

В режиме содержимого **Игнорировать пробелы и табуляцию** исключает ASCII-пробел,
табуляцию, вертикальную табуляцию и перевод страницы. **Игнорировать тип окончания
строк** приравнивает CR, LF, CRLF; отсутствие последнего окончания значимо.
Сравниваются нормализованные байты, без языкового анализа. В отличие от
построчного File Compare, фрагмент из одних пробелов без окончания может стать
пустым текстом. Нужен UTF-8 без NUL до 1 МиБ на сторону. Неподдерживаемый текст
получает «Пропущено», не «Одинаковые». Без параметров бинарные данные сравниваются
точно, потоковыми порциями.

## Статусы и управление

| Статус | Значение |
| --- | --- |
| Одинаковые | Файлы совпали по выбранному методу |
| Различаются | Файлы различны; при разных датах указывается более новая сторона |
| Только слева / Только справа | Путь есть с одной стороны |
| Разные типы | Файл против каталога |
| Каталог | С обеих сторон папки; проверяйте строки потомков |
| Пропущено | Ссылка, специальный файл, неподдерживаемый текст или лимит чтения |
| Ошибка чтения | Нет доступа либо файл изменился; подробности в подсказке строки |

Статус папки не утверждает равенство её содержимого. Обнаруженные ссылки не
обходятся, корень-ссылка отклоняется. При чтении перепроверяются размер, время,
идентификатор и etag, если доступны. Это снимок с проверками, не атомарная
транзакция ФС или защита от намеренной подмены пути.

**Только различия** скрывает одинаковые файлы и парные папки, сохраняя ошибки и
пропуски. Ctrl+F активирует фильтр фрагмента отображаемого пути без учёта регистра
Unicode. Заголовки «Относительный путь» и «Статус» сортируют строки. Фильтр и
порядок сохраняются после обновления. Счётчики различают совпадения, различия,
односторонние пути, типы, пропуски, ошибки и папки. Колонки сторон содержат размер
и местное время изменения.

Ctrl+↑ / Ctrl+↓ и **Предыдущий / Следующий различающийся файл** идут по видимому
порядку, пропуская одинаковые файлы и парные папки, и останавливаются на краях.
Двойной щелчок, Enter или **Сравнить выбранный файл** открывают пару обычных файлов
в новом File Compare. Берутся корни и текстовые параметры завершённого снимка,
даже если поля уже изменены. Файлы перечитываются; действуют лимиты File Compare:
UTF-8, 1 МиБ и LCS. Односторонний файл, ссылка или папка не подменяются пустым файлом.

Контекстное меню копирует относительный отображаемый путь или **видимый список**.
Список — UTF-8 TSV с текущими фильтром/порядком, статусом и метаданными сторон.
Обратная косая черта, табуляция и окончания внутри полей экранируются. Это отчёт
для чтения, не manifest исходных байтов имён. Снимок только для чтения. Копирование
и удаление файлов между каталогами, фильтр известных типов, переменные путей,
сравнение резервных копий и постоянные настройки окна пока не реализованы.

## Лимиты и проверки

По умолчанию: 20 000 путей объединения, 100 000 посещённых элементов двух деревьев,
глубина 32, относительный путь до 16 384 байт. Точное сравнение читает файлы до
64 МиБ на сторону, текстовые параметры — до 1 МиБ. Бюджет 256 МиБ консервативно
списывается по двум размерам снимка до чтения; не поместившаяся пара пропускается.
Разные размеры в точном режиме не требуют чтения. Проверяйте ошибки и пропуски
перед выводом о полноте. Ошибка подкаталога прерывает весь обход.

Meson: **Insight directory comparison snapshots**, **Insight isolated Directory
Compare GUI**, **Insight native Directory Compare routing GUI**. Первые два
локально проходят на Linux с UBSan, строгими предупреждениями и фатальными GLib
criticals. Проверяются методы, бинарные данные, нормализация, скрытые/вложенные
пути, ссылки, лимиты, отмена, фильтр, сортировка, clipboard, сохранённые корни,
пустой результат и закрытие с заданием. Native-тест запускает полный редактор,
команду Tools и проверяет результат настоящего File Compare. Linux CI включает
все три и прежние тесты редактора. Windows и Android в серии не запускались.
