# Сравнение каталогов

Откройте **Инструменты → Сравнение каталогов…** или **Сравнить каталоги…** в File
Compare. Выберите два каталога и нажмите **Сканировать / Обновить**, Enter в пути
или F5. Обход и чтение работают в отменяемом GTask-потоке; строки GTK готовятся
idle-порциями примерно по 3 мс. Отмена, ошибка обхода, неверный корень и лимит
сохраняют прежний снимок. Поздний ответ не обновляет уничтоженное окно.

## Методы и параметры

| Метод | Что означает «Одинаковые» для файлов |
| --- | --- |
| По содержимому | Совпадают байты; даты не влияют |
| По датам изменения | Совпадает время с микросекундами; размер и содержимое не читаются |
| По размерам и датам | Совпадают размер и время; содержимое не читается |

**Включать подкаталоги** разрешает рекурсивный обход; без него сравниваются прямые
потомки. **Включать скрытые элементы** включает имена с точкой и атрибут hidden.
Параметры применяются следующим сканированием. Наблюдения за файловой системой
нет: обновляйте F5. Сопоставляются точные относительные пути с учётом регистра,
даже на нечувствительных к регистру ФС. Корни должны представляться в кодировке
интерфейса; имена потомков хранятся в исходной кодировке и имеют отображаемые имена.

В режиме содержимого **Игнорировать пробелы и табуляцию** исключает ASCII-пробел,
табуляцию, вертикальную табуляцию и перевод страницы. **Игнорировать тип окончания
строк** приравнивает CR, LF, CRLF; отсутствие последнего окончания значимо.
Сравниваются нормализованные байты, без языкового анализа. В отличие от
построчного File Compare, фрагмент из одних пробелов без окончания может стать
пустым текстом. Нужен UTF-8 без NUL до 1 МиБ на сторону. Неподдерживаемый текст
получает «Пропущено», не «Одинаковые». Без параметров бинарные данные сравниваются
точно, потоковыми порциями.

## Статусы и управление

| Статус | Значение |
| --- | --- |
| Одинаковые | Файлы совпали по выбранному методу |
| Различаются | Файлы различны; при разных датах указывается более новая сторона |
| Только слева / Только справа | Путь есть с одной стороны |
| Разные типы | Файл против каталога |
| Каталог | С обеих сторон папки; проверяйте строки потомков |
| Пропущено | Ссылка, специальный файл, неподдерживаемый текст или лимит чтения |
| Ошибка чтения | Нет доступа либо файл изменился; подробности в подсказке строки |

Статус папки не утверждает равенство её содержимого. Обнаруженные ссылки не
обходятся, корень-ссылка отклоняется. При чтении перепроверяются размер, время,
идентификатор и etag, если доступны. Это снимок с проверками, не атомарная
транзакция ФС или защита от намеренной подмены пути.

**Только различия** скрывает одинаковые файлы и парные папки, сохраняя ошибки и
пропуски. Ctrl+F активирует фильтр фрагмента отображаемого пути без учёта регистра
Unicode. Заголовки «Относительный путь» и «Статус» сортируют строки. Фильтр и
порядок сохраняются после обновления. Счётчики различают совпадения, различия,
односторонние пути, типы, пропуски, ошибки и папки. Колонки сторон содержат размер
и местное время изменения.

Ctrl+↑ / Ctrl+↓ и **Предыдущий / Следующий различающийся файл** идут по видимому
порядку, пропуская одинаковые файлы и парные папки, и останавливаются на краях.
Двойной щелчок, Enter или **Сравнить выбранный файл** открывают пару обычных файлов
в новом File Compare. Берутся корни и текстовые параметры завершённого снимка,
даже если поля уже изменены. Файлы перечитываются; действуют лимиты File Compare:
UTF-8, 1 МиБ и LCS. Односторонний файл, ссылка или папка не подменяются пустым файлом.

Контекстное меню копирует относительный отображаемый путь или **видимый список**.
Список — UTF-8 TSV с текущими фильтром/порядком, статусом и метаданными сторон.
Обратная косая черта, табуляция и окончания внутри полей экранируются. Это отчёт
для чтения, не manifest исходных байтов имён. Список остаётся снимком; команды копирования обычных файлов и корзины описаны ниже. Переменные путей и сравнение резервных копий пока не реализованы.

![Производственное окно в изолированном GTK-тесте](../media/directory-compare.jpg)

Это настоящий интерфейс Linux/Xvfb с искусственными файлами, не снимок полного
редактора. Выбранная кириллическая пара совпадает после нормализации пробелов
и окончаний, несмотря на разный размер.

## Лимиты и проверки

По умолчанию: 20 000 путей объединения, 100 000 посещённых элементов двух деревьев,
глубина 32, относительный путь до 16 384 байт. Точное сравнение читает файлы до
64 МиБ на сторону, текстовые параметры — до 1 МиБ. Бюджет 256 МиБ консервативно
списывается по двум размерам снимка до чтения; не поместившаяся пара пропускается.
Разные размеры в точном режиме не требуют чтения. Проверяйте ошибки и пропуски
перед выводом о полноте. Ошибка подкаталога прерывает весь обход.

Meson: **Insight directory comparison snapshots**, **Insight isolated Directory
Compare GUI**, **Insight native Directory Compare routing GUI**. Первые два
локально проходят на Linux с UBSan, строгими предупреждениями и фатальными GLib
criticals. Проверяются методы, бинарные данные, нормализация, скрытые/вложенные
пути, ссылки, лимиты, отмена, фильтр, сортировка, clipboard, сохранённые корни,
пустой результат и закрытие с заданием. Native-тест запускает полный редактор,
команду Tools и проверяет результат настоящего File Compare. Linux CI включает
все три и прежние тесты редактора. Windows и Android в серии не запускались.

**Колонки…** скрывает статус и метаданные сторон до закрытия окна. Относительный
путь остаётся видимым. Скрытие сортируемой колонки сохраняет порядок; копирование
списка по-прежнему включает четыре поля отчёта для видимых строк.

### Маски файлов и статус

Поля **Include masks** (`*.c;*.h`) и **Exclude masks** (`*.o;build/*`) фильтруют готовый снимок без повторного сканирования. Маски GLib учитывают регистр: `*` — любая последовательность, `?` — один символ. Разделитель — точка с запятой; пробелы по краям удаляются. Каждая маска проверяет относительный путь и имя файла. Пустое включение означает все записи; исключение имеет приоритет. Каталоги фильтруются по собственным именам. Выбор статуса сочетается с поиском пути и Differences only. Скрытые строки учитываются в лимитах сканирования. Экспорт и переход по различиям используют видимые строки.

**Swap and scan** меняет местами введённые каталоги и запускает новое сравнение. При ошибке или отмене остаётся предыдущий снимок. **Reset filters** одновременно очищает поиск, маски, статус и Differences only. Контекстное меню копирует полный путь выбранной стороны из завершённого снимка; отсутствующая сторона недоступна. Правка полей каталогов не меняет пути, копируемые из снимка.

### Известные типы файлов

**Show only known file types** при каждом сканировании получает свежий снимок масок типов файлов редактора и расширений языковых профилей. Неизвестные файлы исключаются до чтения содержимого; строки реальных каталогов остаются для обхода и отображения конфликтов типов. Лимиты записей, посещений и глубины применяются ко всему обходу. Распознавание идёт по имени: широкая маска может включать двоичные файлы. После изменения этого параметра нажмите Scan / Refresh. Индивидуальные привязки файлов к профилям не расширяют этот фильтр имён.

**Font & Color…** на панели фильтров и в контекстном меню открывает общий диалог оформления списков. Включите собственное оформление, выберите шрифт, цвет текста и фона. Apply применяет изменения, Cancel сохраняет прежний стиль. Выделение выбранных строк остаётся тематическим. Отключите собственное оформление для возврата к теме. У каждого открытого сравнения свой стиль.

### Запоминание параметров окна

При закрытии сравнения запоминаются введённые каталоги, метод, рекурсивность, скрытые записи, текстовые опции, известные типы, поиск, маски, статус, Differences only, видимость колонок, сортировка, размер окна и оформление списка. Новые окна получают эти параметры. При выходе из редактора в `insight/workbench.conf` сохраняется последнее открытое из ещё существующих окон; если их нет — последнее закрытое. Уже открытые окна независимы. Восстановление параметров не запускает сканирование и не восстанавливает строки результатов. Нажмите Scan / Refresh для нового снимка. Некорректные и неподдерживаемые значения заменяются стандартными; колонка относительного пути всегда видима. Reset filters очищает только фильтры отображения, сохраняя опции сравнения и оформление.

### Копирование и корзина из завершённого снимка

Выберите строку обычного файла и нажмите **Copy left → right…**, **Copy right → left…**, **Trash left file…** или **Trash right file…** на панели либо в контекстном меню. Копирование создаёт отсутствующий файл или заменяет существующий обычный файл. При включённом **Confirm file operations** (по умолчанию) диалог показывает источник и назначение из завершённого снимка, даже после правки полей каталогов. По умолчанию выбрана отмена; отмена диалога ничего не меняет.

Оба пути должны быть закрыты в редакторе, включая неизменённые документы. Проверка повторяется после подтверждения. Во время фоновой задачи окно становится модальным, остальные действия отключаются, а **Cancel file operation** запрашивает отмену. Закрытие окна также отменяет задачу. Отмена не откатывает уже завершённую атомарную замену. После любой попытки, включая ошибку и отмену, список помечается устаревшим, а файловые операции блокируются до успешного Scan / Refresh. Старые строки не выдаются за обновлённое состояние диска.

Копируется не более 64 МиБ точных байтов источника, включая двоичные данные. Текстовые опции сравнения не меняют копируемые байты. Идентификатор, etag, размер и время источника проверяются до и после чтения. Для существующего назначения требуются исходные идентификатор и etag; условная замена GIO предотвращает молчаливую перезапись другой версии снимка. Отсутствующее назначение записывается во временный файл с приватными правами в том же каталоге и переносится без перезаписи и рекурсивного резервного сценария. Одинаковый файл с обеих сторон отклоняется. Корни и родительские компоненты должны оставаться настоящими каталогами; отсутствующие папки не создаются. Операции над папками, ссылками и специальными файлами недоступны. Проверки родителей и etag не являются блокировкой файловой системы.

Операции переносят содержимое: владелец, права, биты исполнения и время не копируются. Для новых и заменяемых данных запрашивается создание файла с приватными правами GIO; автоматических резервных копий и отмены нет. Корзина использует системный механизм без перехода к безвозвратному удалению. При отказе механизма показывается ошибка, источник остаётся на месте.

![Подтверждение операции над файлом сравнения](../media/directory-operation.jpg)

После успешного обновления сохраняется выбранный относительный путь, и строка прокручивается в видимую область, в том числе при изменённой сортировке. Выбор восстанавливается только для существующей строки, проходящей текущие фильтры. Удалённая или скрытая строка не заменяется случайным выбором; отмена и ошибка сканирования сохраняют прежнюю модель и выбор.

**Confirm file operations** управляет подтверждением копирования и корзины и запоминается вместе с параметрами окна. При отключении действие панели или контекстного меню запускается сразу; проверки открытых документов, идентификаторов и etag, отмена и обязательное обновление после попытки продолжают действовать. Некорректное сохранённое значение восстанавливает включённое подтверждение.
