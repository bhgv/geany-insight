# Связанные окна исходников

**Окно → Связать окна исходников…** открывает таблицу связей проекта. В первой строке таблицы находятся выпадающие списки **Главное** и **Ведомое**. Выберите существующую связь: списки и параметры покажут её значения. Изменения подтверждаются кнопкой **Применить связь**. **Удалить выбранную связь** удаляет только одну пару.

![Связанные окна исходников](../media/scroll-links.svg)

Щёлкните правой кнопкой по редактору или корешку вкладки и выберите **Связать окно исходника…**. Первый вызов начинает новую связь с этим файлом слева. Ведомое окно можно выбрать в первой строке таблицы либо повторить команду на другом редакторе или корешке. Повторный выбор того же файла ничего не добавляет. Уже существующая пара, включая обратный порядок, выделяется в таблице без дублирования. Файл может участвовать в нескольких связях.

| Параметр | Действие |
| --- | --- |
| Показывать одновременно | При выборе любого участника связанные файлы открываются рядом, бок о бок |
| Двусторонняя связь | Прокрутка любого участника ведёт второго; иначе главное окно ведёт ведомое |
| Вертикальная / горизонтальная прокрутка | Передавать изменение видимых строк / горизонтального смещения |
| Связать все окна исходников | Синхронизировать все открытые исходники, включая новые |
| Разорвать все связи | Удалить пары и отключить связь всех окон |

В окне совместного показа расположены настоящие редакторы: работают подсветка, редактирование, отмена и повтор, сохранение. Фокус выбирает соответствующий документ для команд редактора. Вертикальные разделители позволяют менять ширину полей. Закрытие окна совместного показа возвращает редакторы в исходные вкладки. Закрытие файла сохраняет связь именованного файла. Выбор строки связи или последующий выбор связанного участника повторно открывает закрытый файл. Недоступный файл сохраняет связь до восстановления доступа.

Связи именованных файлов, направление, флаги совместного показа и оси прокрутки хранятся в **файле проекта** и переживают закрытие проекта и редактора. Для файлов внутри проекта используются относительные пути. Обновляется только группа связей, остальные настройки проекта сохраняются. Исключение файла через управление составом проекта, мастер-список или обновление состава Git удаляет его связи. Несохранённые файлы и связи без проекта доступны только в текущем сеансе.

Прокрутка сохраняет относительное смещение каждого файла с учётом его границ. Цепочки и циклы обходят каждого участника один раз. Используются видимые строки с учётом сворачивания и переноса, а не выравнивание одинаковых строк диффа. Контекст, терминалы, дифф/мерж и предпросмотры ИИ не являются участниками связей. Связывание не изменяет исходный текст. Ограничения: 64 явные связи, до 128 открытых файлов в режиме связи всех окон. Закрытие диалога управления не отключает связи.
