# Заметки

Вспомогательная область для текстовых заметок.

## Управление

Можно писать, выделять, копировать и вставлять текст. Для хранения важного текста отдельным файлом скопируйте его в документ и сохраните.

## Короткий урок

Запишите короткую заметку о текущей задаче. Скопируйте нужный фрагмент в редактор.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [guide.md](guide.md).
