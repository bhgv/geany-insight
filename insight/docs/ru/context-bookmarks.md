# Контекст и закладки

Одиночный клик по подчёркнутому символу в Контексте открывает определение только внутри Контекста. Двойной клик по строке кода открывает показанный файл на этой строке в основном редакторе и центрирует курсор по вертикали. Одиночный переход ждёт системный интервал двойного клика, поэтому не перенаправляет его.

Двойной клик по номеру строки редактора переключает закладку. Синий кружок появляется слева от номера. Книжка на панели открывает немодальный список с поиском: `имя файла:строка> текст`. Выбор записи открывает строку в редакторе. Маркеры Scintilla следуют за вставкой и удалением строк; именованные закладки сохраняют привязки к исходному тексту.

Инструменты → Сравнение / Сведение… открывает внутреннее сравнение. Внешний KСравнение3 необязателен и запускается только своей кнопкой.
