# Файлы проекта

Список файлов текущего проекта.

## Управление

Фильтр сужает список; сортировка меняет порядок имён и путей. Команды добавления и удаления меняют состав проекта.

## Короткий урок

Откройте проект. Введите часть имени в фильтр. Выберите файл для контекста; двойным щелчком откройте его в редакторе.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [guide.md](guide.md).


## Меню и клавиатура списка файлов

Правый клик выбирает файл без изменения Контекста и редактора. Меню открывает файл, копирует имя/полный путь, фильтрует по точному пути, очищает запрос, восстанавливает колонки, выбирает их видимость и открывает эту справку. Команды исходника недоступны на пустом месте и во время обновления снимка.

В списке Ctrl+F переводит фокус в запрос, Ctrl+C копирует имя, Ctrl+Shift+C — полный путь, Ctrl+Enter открывает выбранный файл. Menu или Shift+F10 открывает контекстное меню; Escape возвращает в редактор. Обычное выделение по-прежнему показывает файл в Контексте, двойной клик открывает редактор.

## Сортировка, колонки и история

Сортировка доступна по имени или полному пути; кнопка со стрелкой переключает убывание. Сортировка заголовком обновляет контролы. Изменяйте ширину и порядок заголовков; в «Видимые колонки файлов» можно скрыть «Путь», но «Файл» остаётся видимым. Восстановление колонок возвращает порядок, ширины и видимость, сохраняя запрос и сортировку. Вид, сортировка и история сохраняются отдельно от панелей символов. Значок истории запоминает или выбирает до 16 допустимых запросов файлов (по 256 байт UTF-8), включая маски имён. Enter запоминает запрос перед обычной активацией; очистка истории сохраняет запрос.

Счётчик показывает загруженные совпадающие файлы и «+», если после лимита списка в 10000 строк остаются совпадения; у обхода проекта также есть собственный предел. Уточните запрос для просмотра другой части списка. Полный путь доступен в подсказке строки. Открытие/сохранение/закрытие/активация документа обновляет список после завершения изменения. Совместимость языков продолжает ограничивать доступные файлы.

Урок: найдите `*.cpp`, запомните запрос, выберите файл и скопируйте полный путь через Ctrl+Shift+C. Выберите точный фильтр файла в меню, очистите его, расширьте «Путь» и измените направление сортировки. Перезапуск восстановит вид и историю; Ctrl+Enter на файле откроет его.

## Master File List

Чтобы хранить состав проекта в текстовом файле, сначала используйте «Экспортировать список файлов…» в окне добавления/удаления файлов. Укажите этот существующий файл в поле Master file list и нажмите Apply. Его пути заменяют правила включения; относительные пути считаются от корня проекта. Пустое поле отключает привязку. В настройках проекта путь к MFL сохраняется относительным, если это возможно.

Фоновая задача проверяет MFL примерно каждые три секунды. Внешние добавления/удаления обновляют список проекта и индекс; маски и исключения проекта учитываются. Команды меню «Проект» открывают MFL или немедленно запускают проверку. Сохранение открытого MFL тоже запускает проверку. Отмена индексации приостанавливает фоновые проверки; явная синхронизация, сохранение списка, изменение привязки или применение состава возобновляют их.

Ручные Add/Remove/Remove all сначала обновляют MFL, затем публикуют состав проекта. Каталоги и явные исключения при такой записи разворачиваются в текущий список подходящих файлов; старые явные исключения очищаются, маски остаются. Поэтому внешняя правка MFL может вернуть вручную удалённый файл. Исходники физически не удаляются. Если настройки проекта сохранить не удалось, MFL восстанавливается побайтно, пока его новая версия не изменена извне. Вместе с ETag сравнивается содержимое — это защищает файловые системы с грубыми timestamp. Устаревший диалог и изменившийся снимок не перезаписывают новые данные. Перед изменением состава сохраните или перечитайте открытый несохранённый MFL.

Формат: UTF-8 с необязательным BOM, по одному буквальному пути на строку, LF/CRLF. Существующие каталоги определяются автоматически, суффикс `/` сохраняет тип отсутствующего каталога. Пустые строки пропускаются. Пределы: 2 МиБ, 10000 уникальных путей; ручной обход — до 64 уровней, 4096 каталогов, 100000 записей. Скрытые/генерируемые каталоги и символьные ссылки при обходе не разворачиваются. Ошибка/отсутствие списка сохраняет прежний принятый состав. Path Variables, кавычки и комментарии не интерпретируются. MFL не может совпадать с файлом настроек проекта. Для наблюдения за каталогами остаётся предел 1024; при неполном наблюдении доступно ручное повторное индексирование.
