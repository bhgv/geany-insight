# Файлы проекта

Список файлов текущего проекта.

## Управление

Фильтр сужает список; сортировка меняет порядок имён и путей. Команды добавления и удаления меняют состав проекта.

## Короткий урок

Откройте проект. Введите часть имени в фильтр. Выберите файл для контекста; двойным щелчком откройте его в редакторе.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [guide.md](guide.md).


## Меню и клавиатура списка файлов

Правый клик выбирает файл без изменения Контекста и редактора. Меню открывает файл, копирует имя/полный путь, фильтрует по точному пути, очищает запрос, восстанавливает колонки, выбирает их видимость и открывает эту справку. Команды исходника недоступны на пустом месте и во время обновления снимка.

В списке Ctrl+F переводит фокус в запрос, Ctrl+C копирует имя, Ctrl+Shift+C — полный путь, Ctrl+Enter открывает выбранный файл. Menu или Shift+F10 открывает контекстное меню; Escape возвращает в редактор. Обычное выделение по-прежнему показывает файл в Контексте, двойной клик открывает редактор.

## Сортировка, колонки и история

Сортировка доступна по имени или полному пути; кнопка со стрелкой переключает убывание. Сортировка заголовком обновляет контролы. Изменяйте ширину и порядок заголовков; в «Видимые колонки файлов» можно скрыть «Путь», но «Файл» остаётся видимым. Восстановление колонок возвращает порядок, ширины и видимость, сохраняя запрос и сортировку. Вид, сортировка и история сохраняются отдельно от панелей символов. Значок истории запоминает или выбирает до 16 допустимых запросов файлов (по 256 байт UTF-8), включая маски имён. Enter запоминает запрос перед обычной активацией; очистка истории сохраняет запрос.

Счётчик показывает загруженные совпадающие файлы и «+», если после лимита списка в 10000 строк остаются совпадения; у обхода проекта также есть собственный предел. Уточните запрос для просмотра другой части списка. Полный путь доступен в подсказке строки. Открытие/сохранение/закрытие/активация документа обновляет список после завершения изменения. Совместимость языков продолжает ограничивать доступные файлы.

Урок: найдите `*.cpp`, запомните запрос, выберите файл и скопируйте полный путь через Ctrl+Shift+C. Выберите точный фильтр файла в меню, очистите его, расширьте «Путь» и измените направление сортировки. Перезапуск восстановит вид и историю; Ctrl+Enter на файле откроет его.

## Master File List

Чтобы хранить состав проекта в текстовом файле, сначала используйте «Экспортировать список файлов…» в окне добавления/удаления файлов. Укажите этот существующий файл в поле Master file list и нажмите Apply. Его пути заменяют правила включения; относительные пути считаются от корня проекта. Пустое поле отключает привязку. В настройках проекта путь к MFL сохраняется относительным, если это возможно.

Фоновая задача проверяет MFL примерно каждые три секунды. Внешние добавления/удаления обновляют список проекта и индекс; маски и исключения проекта учитываются. Команды меню «Проект» открывают MFL или немедленно запускают проверку. Сохранение открытого MFL тоже запускает проверку. Отмена индексации приостанавливает фоновые проверки; явная синхронизация, сохранение списка, изменение привязки или применение состава возобновляют их.

Ручные Add/Remove/Remove all сначала обновляют MFL, затем публикуют состав проекта. Каталоги и явные исключения при такой записи разворачиваются в текущий список подходящих файлов; старые явные исключения очищаются, маски остаются. Поэтому внешняя правка MFL может вернуть вручную удалённый файл. Исходники физически не удаляются. Если настройки проекта сохранить не удалось, MFL восстанавливается побайтно, пока его новая версия не изменена извне. Вместе с ETag сравнивается содержимое — это защищает файловые системы с грубыми timestamp. Устаревший диалог и изменившийся снимок не перезаписывают новые данные. Перед изменением состава сохраните или перечитайте открытый несохранённый MFL.

Формат: UTF-8 с необязательным BOM, по одному буквальному пути на строку, LF/CRLF. Существующие каталоги определяются автоматически, суффикс `/` явно обозначает каталог (отсутствующий каталог отклоняет снимок). Пустые строки и строки с начальным `;` пропускаются. Настоящее имя с начальным `;` записывается как `./;имя`, чтобы не превратиться в комментарий при повторном чтении. Ручная запись состава создаёт канонические строки путей; защищённый откат сохраняет исходные BOM, CRLF и комментарии побайтно. Пределы: 2 МиБ, 10000 уникальных путей; ручной обход — до 64 уровней, 4096 каталогов, 100000 записей. Скрытые/генерируемые каталоги и символьные ссылки при обходе не разворачиваются. Ошибка/отсутствие списка сохраняет прежний принятый состав. В строках самого MFL переменные не разворачиваются; поле привязки поддерживает проектные переменные, описанные ниже. Кавычки пока не поддерживаются. MFL не может совпадать с файлом настроек проекта. Для наблюдения за каталогами остаётся предел 1024; при неполном наблюдении доступно ручное повторное индексирование.

Эталон: [руководство Source Insight 4](https://www.sourceinsight.com/doc/v4/userguide/Manual/Concepts/Using_a_Master_File_List.htm).

Начните фильтр списка с `~` для нечёткого поиска по Unicode-подпоследовательности без учёта регистра: `~srd` находит `Shared`. Обычный запрос ищет буквальную подстроку, включая пробелы и знаки. Один `~` ничего не находит.

## Команды перехода к диску

В запросе Project Files введите `.` и нажмите Enter: каталог workspace откроется в Folders → Просмотр диска. `..` открывает его родительский каталог. Команда `**` с Enter очищает фильтр и возвращает фокус в Project Files, не открывая первый файл. Эти специальные команды не добавляются в историю фильтров. Остальные запросы и действия Enter сохраняются. В дисковом браузере доступны собственные путь, кнопка Вверх, фильтр и навигация. Возврат к проектному режиму Folders отменяет незавершённое чтение диска.

### Маски имён в MFL

`src/*.c` и `tw?.c` включают подходящие обычные файлы непосредственно из указанного каталога. Поддерживаются `*` и `?`; в Windows регистр не учитывается, на остальных платформах учитывается. Дочерние каталоги и символьные ссылки не разворачиваются. Существующий буквальный путь имеет приоритет перед маской. Отсутствие совпадений допустимо. Скобочные выражения, маски компонентов каталога, переменные в строках самого MFL и кавычки пока не поддерживаются.

Обход выполняется в фоновом потоке синхронизации с отменой. Пределы снимка: 256 правил каталогов/масок, 1024 байта на шаблон имени, 100000 просмотренных записей и прежние 10000 уникальных включённых путей. Ошибка или превышение сохраняет ранее принятый проект. Появление/исчезновение подходящих файлов обновляет состав, даже если MFL не менялся. Ручная запись отклоняет изменившийся набор совпадений; успешная запись разворачивает маски в явные пути. Изменения во время обхода согласуются следующими проверками; это не атомарный снимок файловой системы.

### Каталоги в MFL

Каталог включает только обычные файлы известных типов непосредственно внутри него, без рекурсии, как в Source Insight. Учитываются шаблоны имён Geany (без универсального типа None), расширения пользовательских языков и точные привязки языка к файлам. Поэтому Makefile определяется штатным шаблоном, а необычное расширение — явной привязкой языка. Явные строки файлов и маски имён не ограничиваются известными типами. Дочерние символьные ссылки пропускаются; каталог-ссылка отклоняет снимок. Отсутствующий каталог сохраняет прежний принятый проект.

Фоновые проверки обнаруживают появление/исчезновение файлов без переписывания текста MFL. Изменения языковых профилей обновляют снимок известных типов и отменяют устаревшие задачи. Каталоги и маски делят пределы 256 правил/100000 просмотренных записей. Снимок допускает 4096 штатных шаблонов, 4096 расширений и 10000 точных привязок; некорректный снимок не публикует частичный состав.

Изменение совместимости: прежние версии порта разворачивали каталоги MFL рекурсивно. Для нужных вложенных файлов добавьте явные строки подкаталогов/файлов или маски имён. Отдельная команда Add Tree сохраняет рекурсивное поведение. Ручная запись состава по-прежнему разворачивает правила в явные пути. Проверены Linux core/service/GUI; Windows GUI пока не проверен.

### Переменные проекта в пути к MFL

Поле Master file list поддерживает `%PROJECT_SOURCE_DIR%` — корень исходников проекта, `%PROJECT_DATA_DIR%` — каталог файла `.geany`, `%PROJECT_NAME%` — имя этого файла без последнего расширения. Регистр имён не учитывается. `%PROJECT_SOURCE_DIR%/master.txt` следует за перенесённым корнем; `%PROJECT_DATA_DIR%/%PROJECT_NAME%.txt` — за расположением и именем файла проекта.

Раскрытие однопроходное: до 32 подстановок, 16384 байта на выражение и результат. Неизвестная/недоступная переменная или некорректное выражение показывает ошибку и блокирует Apply, не меняя прежнюю привязку кандидата. `%%` означает буквальный процент; Browse автоматически экранирует имена файлов. Разрешение выражения не выполняет файловый ввод-вывод. Системные/пользовательские переменные и раскрытие в остальных настройках остаются открытыми пунктами.

Выражение сохраняется отдельно в `master-file-expression` рядом с разрешённым, по возможности относительным `master-file` в прежних настройках состава версии 1 и пересчитывается при загрузке проекта. Старые настройки без нового ключа остаются буквальными, включая знаки процента. Отключение MFL удаляет оба ключа. Значения переменных вставляются как буквальный текст пути и повторно не раскрываются.

### Системные каталоги и окружение в пути MFL

Поле пути MFL раскрывает имена переменных окружения без учёта регистра и
`%TEMP_DIR%`, `%DESKTOP_DIR%`, `%MYDOCUMENTS_DIR%`, `%APPDATA_DIR%`,
`%LOCAL_APPDATA_DIR%`. В Windows также доступны `%PROGRAMFILES_DIR%`,
`%PROGRAMFILESX86_DIR%`, `%WINDOWS_DIR%` из соответствующих переменных процесса.
В Unix APPDATA/LOCAL_APPDATA означают каталоги конфигурации/данных GLib.
Недоступные специальные каталоги, пустые значения, некорректный UTF-8,
переносы строк и различные значения одноимённых переменных с разным регистром
отклоняются без изменения прежнего пути. Окружение фиксируется на одну
операцию; подставленные значения повторно не раскрываются. Выражение
сохраняется и вычисляется заново при загрузке проекта. Для получения нового
окружения оболочки нужно перезапустить редактор. Отдельный редактор
пользовательских переменных и остальные специальные каталоги Source Insight
пока не реализованы; строки внутри самого MFL сохраняют буквальные пути.

Столбцы «File», «Directory», «Size», «Path» показывают имя, каталог, размер в байтах и полный путь. Размер сортируется численно; для отсутствующего или недоступного файла поле пустое. Данные читаются в фоновом потоке при обновлении списка.

### Команды масок в Project Files

Enter после корректной маски (`z.c?p`, `*.c`) оставляет отфильтрованный список,
не открывая первый файл, в том числе во время фонового обновления. `*` + Enter
снимает фильтр; эта команда не попадает в историю. `**` сохраняет прежний возврат
к проектному режиму. Обычные фрагменты, regex и точные запросы в кавычках
сохраняют открытие по Enter. Маска без совпадений оставляет пустой список.

Маска без разделителей пути сравнивается с именем файла независимо от каталога.
`Т?ст.c` находит `inner/Тест.c`, а `*.cpp*` не включает `folder.cpp/notes.h`.
Маски с разделителями и явные `@path` по-прежнему сравниваются с полным путём;
для файлов такого каталога используйте `*folder.cpp/*`. Прежние правила
фрагментов/regex/точного/нечёткого поиска, языковой совместимости и пределы
списка сохраняются.

Старые раскладки File/Path из двух колонок сохраняют взаимный порядок, ширины
и корректную видимость при загрузке четырёхколоночного списка. Directory/Size
добавляются в конец с исходными настройками; некорректные раскладки оставляют
значения по умолчанию. Сброс восстанавливает File/Directory/Size/Path с
соответствующими ширинами.
Эталон: [Source Insight Project File List](https://www.sourceinsight.com/doc/v4/userguide/Manual/Concepts/Project_File_List.htm).

## Управление окном панели

В заголовке: **Открепить / Закрепить** и **Развернуть / Восстановить**.
Разворачивание доступно в плавающем окне. Закрепление возвращает панель
на штатное место и выбирает вкладку; системное закрытие также закрепляет её.
Размеры и развёрнутое состояние отдельных панелей сохраняются в раскладках A–D. Произвольные места закрепления пока не поддерживаются.

### Полоса свёрнутых окон (Tab Tray)

Кнопка сворачивания переносит плавающую панель в нижнюю полосу. Нажмите её имя,
чтобы восстановить окно. View → Panels → Tab Tray скрывает/показывает полосу,
оставляя панели свёрнутыми. Restore minimized panels восстанавливает все
свёрнутые панели. Пустая полоса скрывается автоматически. Раскладки и настройки
сеанса запоминают свёрнутые панели и видимость полосы. Отдельное окно Window List
и целая группа Project Window в эту полосу пока не включены.
