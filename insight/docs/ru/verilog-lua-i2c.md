# Устройство I²C на Lua

Добавьте правило в **Port Signals**. Короткая форма использует
`scl sda` и адрес `0x50`. В полной форме можно задать порты,
запасной адрес и активный нулём сброс. Устройства с разными адресами
могут делить SCL и SDA. Относительный путь отсчитывается от каталога
исходника схемы.

```text
i2c-lua "i2c-registers.lua"
i2c-lua scl sda 0x52 "i2c-address.lua" reset_n
```

Каждый экземпляр имеет собственное состояние Lua и поток ОС.
Все функции необязательны.

| Функция | Поведение |
| --- | --- |
| `reset()` | Вызывается при запуске и сбросе. Сброс очищает очередь. |
| `address(header)` | Получает исходный 8-битный адресный байт, включая младший бит R/W. true принимает обращение и выдаёт ACK, false оставляет SDA отпущенной. Если функции нет, используется адрес из настройки. |
| `write(byte)` | Вызывается для каждого байта данных принятой записи. |
| `receive(bytes)` | Вызывается по STOP или повторному START после принятой записи. Таблица с индексом от 1 содержит только байты данных. |
| `read()` | Вызывается, если ведущий запрашивает байт, а очередь пуста. |

`write`, `receive` и `read` могут вернуть nil, один байт или несколько.
nil ничего не добавляет. Числа от 0 до 255 передаются ведущему при
чтении в порядке возврата. Пока очередь содержит байты, чтение
использует её без вызова `read` или `receive`. Если очередь пуста и
`read` возвращает nil, ведомое устройство отпускает SDA на тактах
данных. При подтяжке ведущий считывает FF. Очередь и кадр ограничены
4096 байтами.
