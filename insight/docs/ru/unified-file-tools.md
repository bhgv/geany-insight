# Единый поиск в файле и символы файла

Дублирующие интерфейсы Geany и Insight объединены: Ctrl+F, меню и кнопка поиска, Quick Find открывают одну строку File Search. F3/Shift+F3 (или назначенные клавиши следующего/предыдущего совпадения) используют её запрос и параметры. Поиск выделенного текста также может заполнить общее состояние. Замена и поиск по проекту остаются отдельными задачами.

Выпадающее поле хранит последние 32 успешных запроса текущего сеанса. Родная команда перехода к символам также направляется в выбранный режим общей панели.

Порядок элементов повторяет File Search Bar Source Insight: запрос, Next/Previous, Search Files, Options, Wrap around и Match case. В Options сохранены Find All in Document/Open Documents и Mark All из Geany для обычных запросов и regex (для нечёткого запроса выводится ограничение). В Options находятся целые слова, Perl-совместимый regex, выделение совпадения, поиск при вводе и загрузка слова под курсором при нажатии кнопок перехода. Escape закрывает строку и возвращает фокус редактору. Второе окно Find при активном рабочем интерфейсе больше не создаётся. Search Files открывает поиск по проекту/файлам. Нечёткий поиск ~term сохранён при выключенном regex. Поиск активного файла использует диапазон позиций редактора, включая файлы больше 2 МиБ; фоновые операции и поиск в предпросмотре сохраняют прежние ограничения. Find All/Mark учитывают многострочность и границы целых слов Unicode для regex, как и строка поиска. Контекстно-зависимый поиск символов и старый диалект regex Source Insight здесь не реализованы. Параметры действуют в текущем сеансе.

Слева одна вкладка File Symbols на месте прежней вкладки Symbols. По умолчанию выбран **Structure** — настоящее дерево ctags Geany с категориями, классами, членами, сворачиванием, переходами и контекстным меню. Внизу сортировка по имени и порядку в исходнике. Светлый фон, квадратные значки типов, линии дерева и полужирные структуры оформлены по эталону Symbol Window Source Insight. Отрисовка GTK/шрифтов и дерево конкретного парсера зависят от платформы; попиксельное совпадение не заявляется.

**Detailed symbols** переключает ту же панель на расширенный список Insight: запросы по полям, история, фильтры типов, группировка областей, колонки, Symbol Info, ссылки и поиск символа у каретки сохранены. Поле запроса одно. В Structure работает родной фильтр имён с разделением пробелами; расширенный синтаксис предназначен для Detailed symbols. Enter в Structure переводит фокус на первую подходящую декларацию. Отсоединение и возврат панели сохраняют позиции родных вкладок боковой области. Documents остаётся отдельной вкладкой.
