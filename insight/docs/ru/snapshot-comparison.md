# Сравнение снимков

**Файл → Сравнить с резервной версией…** позволяет выбрать сохранённую версию и сравнить её с исходным буфером, включая ещё не записанные правки. В окне резервных версий есть и кнопка **Сравнить с текущим буфером**. При запуске сравнения исходный документ должен ещё существовать под показанным именем. Сведения о выбранной резервной версии повторно проверяются перед чтением.

Дополнительные команды меню «Файл»: **Сравнить текущий буфер с диском** и **Сравнить текущий буфер с исходным**. Для диска нужен обычный файл UTF-8; один файловый BOM удаляется при чтении, другие кодировки не преобразуются. Исходное содержимое — декодированный снимок при открытии либо новая исходная точка после [Checkpoint](checkpoint.md). Обычный Save этот снимок не заменяет. Три команды доступны в браузере команд и настройках клавиш редактора, без сочетаний по умолчанию.

![Настоящее окно сравнения GTK-редактора](../media/snapshot-comparison.jpg)

В окне две текстовые панели только для чтения и список вставленных, удалённых и изменённых блоков строк. Слева — резервная, дисковая или исходная версия; справа — снимок буфера. Заголовки указывают версии. Выбранный блок выделяет оба диапазона и прокручивает панели. На пустой стороне вставки/удаления показана нулевая по ширине **граница**. Номера логических строк начинаются с единицы, CRLF считается одним переводом строки. **Предыдущее различие** и **Следующее различие** останавливаются у края списка.

**Копировать отчёт о различиях** копирует весь показанный список блоков в TSV: английская строка заголовков, локализованные названия строк, не более 1 МиБ. В отчёте диапазоны, а не полный текст исходников. При пустом списке кнопка недоступна. В самих панелях можно обычным способом выделять и копировать текст.

**Игнорировать пробелы и табуляцию** и **Игнорировать стиль перевода строк** действуют независимо, через существующее ядро сравнения. Регистр учитывается; отсутствие завершающего перевода строки остаётся различием. Изменение опций сразу очищает список и подсветку. Для пересчёта нажмите **Сравнить**. Пустой список означает отсутствие различий при выбранных опциях, а не обязательно побайтовое равенство.

![Сравнение захваченных снимков](../media/snapshot-comparison.svg)

Сравнение выполняется над собственными копиями текста в фоновом задании с отменой. Повторная кнопка **Сравнить** использует те же захваченные данные, не перечитывая изменённый исходник или резервную версию. Для нового состояния закройте окно и снова вызовите команду. Текст, выделение, Undo/Redo, исходный снимок и диск не меняются. В этом окне нет слияния, применения или сохранения результата; для слияния есть отдельное [окно Diff / Merge](internal-diff.md).

Обеим сторонам нужен корректный UTF-8 без NUL, не более 1 МиБ. Двустороннее построчное сравнение ограничено 4 миллионами ячеек LCS. Недоступные, некорректные и слишком большие снимки не открывают окно. Превышение объёма работы и отмена очищают результаты и показывают статус. Закрытие работающего окна отменяет задание и исключает позднее обновление уничтоженных виджетов. Данные и опции не сохраняются между окнами и перезапусками редактора. Слежения за правками и перехода обратно в живой исходник нет.

На Linux проверяются три команды меню и клавиш, выбор/отмена резервной версии и закрытый исходник, неизменность снимков, диапазоны смешанных EOL, переходы и отчёт, сохранность исходного текста/выделения/Undo/диска, режим только для чтения, различие обычного сохранения и исходной точки, опции, регистр, ограничения размера/NUL/объёма работы, отмена и уничтожение окна. Скриншот получен из настоящего окна тестом под Xvfb. Windows и Android не запускались.

Основа Source Insight: [Compare with Backup File](https://www.sourceinsight.com/doc/v4/userguide/Manual/Command_Reference/Compare_with_Backup_File.htm). Команды сравнения с диском/исходным и отдельное окно снимков только для чтения — расширения Geany Insight. См. [Резервные версии](backup-versions.md).
