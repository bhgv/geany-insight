# Навигация

Меню «Навигация» объединяет переходы в исходнике и управление окном связей. Команды не являются заглушками: результат может быть переходом курсора, списком совпадений, сменой вида графа или переключением состояния блокировки.

| Команда | Результат |
| --- | --- |
| Назад / вперёд | История позиций редактора, как стрелки главного тулбара и меню редактора |
| Назад / вперёд контекста | Отдельная история просмотренных определений; исходник редактора не переключается |
| К определению / прототипу / реализации / базовому типу | Переход к найденному определению или выбор среди результатов |
| Jump To Caller / Ссылки / Члены / Производные типы | Окно связей с уже заполненным символом под курсором и запущенным запросом; выбор результата открывает его исходник |
| Функция выше / ниже | Следующая или предыдущая функция по свежим тегам текущего буфера |
| Горизонтальный / вертикальный граф | Раскрывает окно связей и меняет представление уже полученных данных |
| Заблокировать контекст / связи | Сохраняет текущий результат вместо автоматического следования за курсором; повторный выбор возвращает слежение |

Вызовы и ссылки являются лексическими, а члены и наследование основаны на тегах — это не полный компиляторный анализ. Для проектных результатов откройте проект и дождитесь готовности индекса. Если символа, истории или подходящей функции нет, команда сообщает причину в строке состояния; штатные стрелки истории отключаются, когда переход недоступен.

Команда раскрывает нужную панель, вложенные вкладки и почти полностью сжатую полку. Для самостоятельного окна панель поднимается на передний план. Параметры окна связей сгруппированы во вкладки «Запрос», «Фильтры», «Вид», «Навигация» и «Свернуть».
