# Терминал

Встроенный терминал, если он доступен в данной сборке.

## Управление

Терминал выполняет команды локальной оболочки. Доступность зависит от платформы и поддержки VTE. Для удалённых команд предусмотрена отдельная панель SSH.

## Короткий урок

Выберите вкладку терминала и выполните безопасную команду вывода текущего каталога. Для SSH откройте соответствующую панель.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [panel-ssh.md](panel-ssh.md).
