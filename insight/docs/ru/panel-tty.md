# TTY / COM — последовательный терминал

Вкладка TTY Terminal находится рядом с SSH Terminal на нижней полке. Справа — иконка подключения и нумерованные терминалы; вкладки передачи нет. Кнопка **+** создаёт независимый терминал, до 16.

![Устройство терминалов](../media/terminals.svg)

Список портов обновляется при открытии вкладки подключения и кнопкой Refresh ports. Windows перечисляет COM1–COM256, известные системе; Unix — обычные ttyS/ttyUSB/ttyACM/rfcomm и macOS tty./cu. в /dev. Можно вручную ввести имя устройства, в том числе PTY для проверки. При обновлении введённый путь сохраняется. Перечисление не открывает оборудование.

Выберите скорость 300–230400 из списка, 5/6/7/8 бит данных, 1/2 стоп-бита, чётность None/Even/Odd и при необходимости Local echo, затем Connect. По умолчанию — 115200, 8N1, без локального эха. Параметры применяются к выбранному терминалу при подключении; драйвер может отклонить неподдерживаемое сочетание. Disconnect закрывает только выбранное соединение. Управление потоком отключено; управление модемными линиями, BREAK, протоколы передачи файлов и сохранение профилей пока не добавлены. Права на Unix-устройства остаются под управлением ОС.

Ввод и вывод находятся в одном чёрном поле. Есть выделение мышью, Ctrl+Shift+C/V, Shift+Insert и меню Copy/Paste. Средняя кнопка вставляет выделение самого терминала; если его нет — выделение PRIMARY, а при его отсутствии — текст буфера обмена. Вставка может содержать переводы строк; удалённая программа определяет их действие. Если она включает bracketed paste, вставка обрамляется соответствующими последовательностями.

SSH и TTY используют встроенный libvterm 0.3.3 с лицензией MIT: потоковый UTF-8, команды VT100/xterm управления курсором, очистки и прокрутки, DEC-графику, SGR 16/256/RGB, альтернативный экран, режим клавиш курсора, управляющие клавиши и ответы терминала. Текущий экран — **80 столбцов × 24 строки**, по начальному размеру PTY клиента OpenSSH с каналами ввода/вывода. Изменение размеров панели прокручивает экран, но не согласует новый размер с удалённой программой. Штатный локальный VTE сохраняет собственное изменение размеров. История ограничена 2000 строками / 4 МиБ ячеек; кэш цветов — 4096 тегами. Мышь выделяет текст; протоколы mouse reporting не включены. Запросы OSC к системному буферу обмена не подключены.

На Windows используются асинхронные overlapped-операции COM, на Unix — неблокирующий termios с восстановлением прежних настроек при закрытии. Очередь ввода — до 1 МиБ. Ошибка обмена закрывает соединение и показывает причину. Кодировка терминала — UTF-8; двоичная передача файлов и старые DOS-кодировки вне этого этапа. Проверка Linux использует настоящую пару псевдотерминалов и loopback OpenSSH. Физическое RS-232-оборудование и выполнение на Windows не проверялись.
