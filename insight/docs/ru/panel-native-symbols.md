# Символы Geany

Исходный список символов Geany для текущего файла.

## Управление

Дерево раскрывается по категориям. Контекстное меню содержит параметры исходного списка. Панель «Символы файла» Insight предоставляет дополнительные фильтры, цвета и группировку.

## Короткий урок

Выберите вкладку символов, раскройте функции и выберите определение для перехода.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [panel-file-symbols.md](panel-file-symbols.md).
