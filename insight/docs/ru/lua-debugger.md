# Отладчик Lua

Откройте файл Lua и выберите **Скрипты → Debug Current Lua Buffer…**.
Отладчик берёт снимок буфера вместе с несохранёнными правками и останавливается
на первой исполняемой строке. Кнопка **?** в правом верхнем углу открывает эту
инструкцию.

## Выполнение и точки останова

| Команда | Клавиша | Действие |
| --- | --- | --- |
| Continue | F5 | Выполнять до точки останова или завершения скрипта |
| Step Over | F10 | Сделать шаг без входа в вызываемую функцию |
| Step Into | F11 | Остановиться на следующей строке Lua, в том числе внутри вызова |
| Step Out | Shift+F11 | Продолжать до возврата в вызывающую функцию |
| Pause | Pause | Запросить паузу на ближайшей доступной строке Lua |
| Stop | Shift+F5 | Завершить выполнение и сохранить список точек останова |
| Restart | Ctrl+F5 | Запустить исходный снимок заново |
| Go to Source | | Открыть строку остановки, если буфер редактора совпадает со снимком |

Щёлкните по номеру строки, чтобы поставить или снять точку останова.
Номера также можно ввести вручную через пробел или запятую. Слева
подсвечивается строка остановки. Вкладка **Stack and locals** показывает
стек вызовов и локальные переменные. Lua выполняется короткими порциями между
событиями интерфейса. Во время нативного вызова пауза возможна после его
возврата. Лимит памяти Lua сохраняется.

На паузе наведите указатель на имя переменной в исходнике отладчика. Подсказка покажет значение локальной переменной, захвата или простого поля, например `config.device.name`. Доступны значения текущего кадра из снимка. Подсказка читает поля напрямую и не вызывает метаметоды.

## Отладка проекта Lua

Точка входа по умолчанию — текущий Lua-файл. Команда **Скрипты → Debug Lua File…** позволяет выбрать другой. При открытом проекте `require("net.codec")` ищет `net/codec.lua` или `net/codec/init.lua` в его корневом каталоге. При первой загрузке отладчик берёт снимок модуля, включая несохранённые правки открытой вкладки. Шаги и точки останова работают в точке входа и загруженных модулях. Чтобы поставить точку до первого перехода в модуль, нажмите **Breakpoints in File…**, выберите файл и укажите номера строк. Точки хранятся отдельно для каждого файла и восстанавливаются при следующем запуске отладки. Для каждого языка настройки привязаны к проекту Geany или, вне проекта, к файлу точки входа. Для буферов без имени точки действуют только в текущем сеансе отладки. Номера строк сохраняются как есть.

Отладчик загружает текстовые модули проекта. Системный поиск пакетов и загрузка нативных модулей Lua в этой VM недоступны. Перезапуск сохраняет уже загруженные снимки. Для проверки новых правок откройте новую сессию.

## Граф наблюдения

На паузе откройте вкладку **Watch graph**. От **Current frame** идут стрелки к
локальным значениям, полям таблиц, реальным метатаблицам и переменным,
захваченным замыканиями. Например, поле таблицы, запись её метатаблицы и
захват лямбды могут ссылаться на одну таблицу. Все три стрелки сойдутся к
одной карточке. Самоссылки отображаются циклом.

Дважды щёлкните по карточке члена или выделите её и нажмите **Pin member**.
Режим **Pinned only** выносит закреплённые члены в отдельные корни.
Их пути вычисляются заново на каждой остановке. **Unavailable** показывает,
сколько путей сейчас вне области видимости или за пределами снимка.
**Clear pins** снимает все закрепления. Чтобы увидеть полные подписи
входящих и исходящих связей, выберите карточку и задержите указатель над графом.

Оранжевые карточки обозначают новые значения или изменения значения и прямых
связей с предыдущей остановки. Перезапуск сбрасывает историю сравнения.
Отладчик читает данные напрямую, без выполнения замыканий и метаметодов.
Стрелка к метатаблице показывает сохранённые ссылки, а не результат вызова
`__index`. Неявный захват `_ENV` пропускается. Снимок ограничен 96 карточками,
224 связями, шестью уровнями вложенности и 16 элементами на таблицу.

## Доступ к редактору и проекту

Вызовы `editor.*` на чтение возвращают сохранённые текст, выделение, позицию
курсора, имя и строки буфера. `project.*` читает индекс, пока активен
исходный проект. Для открытия, записи и изменения документов используйте
обычный запуск Lua-скриптов. Перезапуск повторно использует первоначальный
снимок. Чтобы включить новые правки исходника, откройте новое окно отладчика.
