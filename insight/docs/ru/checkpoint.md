# Контрольная точка: Checkpoint и Checkpoint All

**Файл → Контрольная точка…** сохраняет текущий файл, очищает Undo/Redo и историю изменений, затем делает сохранённый текст новым **Исходным содержимым**. **Контрольная точка для всех…** выполняет это для каждой открытой вкладки. Команды доступны в браузере команд и настройках клавиш редактора; сочетания по умолчанию не назначены.

![Подтверждение в работающем GTK-редакторе](../media/checkpoint.jpg)

В окне показаны полные пути файлов и состояние «Изменён» или «Сохранён». По умолчанию выбрана **Отмена**. Кнопка **Сохранить и сбросить историю** необратимо удаляет прежнюю историю текста, кодировки и BOM. Новые правки снова можно отменять. «Восстановить строки», «Восстановить файл», список и переходы по исходным изменениям теперь сравнивают с контрольной точкой. Обычное сохранение исходный снимок по-прежнему не сбрасывает.

![Порядок выполнения](../media/checkpoint.svg)

Файлам нужны имена и разрешение записи. Сначала сохраните безымянные вкладки; перед командой для всех закройте справочные вкладки только для чтения. Изменение текста, кодировки, BOM, пути, доступности записи или набора целевых вкладок во время подтверждения отменяет операцию. Чистые вкладки тоже включаются; молчаливого пропуска файлов нет.

Сначала сохраняются все файлы, только затем сбрасывается история. Ошибка сохранения, изменение другого целевого файла обработчиком сохранения или невозможность удержать снимок сохраняют историю всех участников. Часть файлов при этом уже может быть записана: общей дисковой транзакции нет. Настройки пробелов и переводов строк при сохранении действуют как обычно; внешние изменения файла обрабатываются штатными средствами Geany.

Снимки поддерживают корректный UTF-8 без NUL: до 8 МиБ на файл и 64 МиБ суммарно с остальными исходными снимками. При неудаче прежние исходные снимки сохраняются. Команда не создаёт резервную копию или Git-коммит.

На Linux проверены настоящее окно редактора, отмена, устаревшие запросы, закрытие/добавление вкладок, ограничения записи и безымянных файлов, меню и клавиши обеих команд, вмешательство обработчика сохранения, история BOM и текста, Undo/Redo, некорректный UTF-8, содержимое диска и новый исходный снимок. Скриншот настоящего диалога получен тестом под Xvfb. Windows и Android не запускались.

Основа: Source Insight 4 — [Checkpoint](https://www.sourceinsight.com/doc/v4/userguide/Manual/Command_Reference/Checkpoint.htm) и [Checkpoint All](https://www.sourceinsight.com/doc/v4/userguide/Manual/Command_Reference/Checkpoint_All.htm). В этой реализации добавлены подтверждение и ограничения памяти снимков.
