# Символы текущего файла

Функции, типы и переменные текущего буфера.

## Управление

Фильтр, сортировка и информация о символе работают с текущим файлом. Цвета и значки совпадают с панелью проекта. Переключатель группировки создаёт группы по типам; выбор сохраняется при перестроении.

## Короткий урок

Откройте файл с функциями и структурами. Включите группировку. Выберите функцию для Контекста, затем откройте её двойным щелчком.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [panel-project-symbols.md](panel-project-symbols.md).


## Фильтр типов символов

Кнопка с воронкой открывает список категорий с флажками: функции/методы, типы/структуры, перечисления, константы перечислений, макросы, поля, переменные, локальные переменные, пространства имён/включения и прочие. Отмеченные категории остаются видимыми. «Показать все» сбрасывает ограничения; «Скрыть все» позволяет выбрать только нужные категории.

Фильтр работает вместе с поиском по имени и группировкой, не удаляет символы из индекса. Счётчик показывает число видимых записей и число записей, загруженных по фильтру имени. Настройки сохраняются отдельно для панели файла и панели проекта. Состав типов зависит от парсера языка; начальный список содержит до 2000 символов файла или 500 символов проекта, подходящих под запрос. Дозагрузка добавляет следующую порцию.

Урок: скройте всё, отметьте только функции/методы, найдите часть имени и включите группировку. Затем снимите ограничение командой «Показать все».


## Контекстное меню и клавиатура

Правый клик по строке выбирает её без смены Контекста и редактора. Меню открывает определение, Symbol Info, лексические ссылки; копирует имя или расположение «путь:строка» для сохранённого файла. Для символа или группы доступны «Показать только эту категорию» и «Скрыть эту категорию»: категория соответствует списку кнопки с воронкой. Также можно показать все типы, включить группировку, развернуть/свернуть все группы и открыть эту справку. На заголовке группы команды открытия исходника отключены.

Из списка Ctrl+F возвращает фокус в его фильтр имён; Ctrl+C копирует имя, Ctrl+Shift+C — расположение сохранённого файла. Ctrl+Enter открывает выбранный символ и центрирует строку (на группе переключает её раскрытие); Alt+Enter открывает Symbol Info. Escape возвращает фокус редактору. Shift+F10 или клавиша Menu открывают контекстное меню.

Урок: сверните группы через меню, перейдите в фильтр и нажмите стрелку вниз. Первая группа раскроется, будет выбран первый символ, а редактор останется на месте. Нажмите Ctrl+Enter для перехода. Затем правой кнопкой выберите группу и оставьте только её категорию; верните остальные командой «Показать все типы».

Пока список обновляется, переходы из поля фильтра временно отключены: старый результат не открывается.


## Дозагрузка большого списка

Знак «+» после общего числа в счётчике означает, что есть ещё подходящие по имени символы. Кнопка «+» рядом со счётчиком и команда «Загрузить ещё символы» в контекстном меню добавляют следующие 2000 записей файла или 500 записей проекта. У кнопки нет надписи; её подсказка указывает размер порции. Когда список исчерпан, кнопка скрывается, а отметка «+» исчезает.

Фильтр типов применяется к загруженным записям. Если нужная категория пока пуста, можно дозагрузить следующую порцию или уточнить имя: поиск имени проверяет весь доступный индекс. Новый запрос сбрасывает размер порции; смена файла сбрасывает список файла, а смена проекта или языкового профиля — список проекта. Дозагрузка не двигает редактор и выполняется в фоне. Предельный размер индекса остаётся 250000 символов.

Урок: откройте большой файл, оставьте только функции, найдите счётчик с «+» и нажмите кнопку дозагрузки. Если функция находилась за начальной порцией, она появится в списке. Для быстрого поиска известного имени введите его в фильтр вместо многократной дозагрузки.


## Сортировка списка

Выбор сортировки предлагает имя, строку исходника, тип символа, область видимости и путь файла. Кнопка со стрелкой рядом переключает порядок по убыванию; название отображается в подсказке. Щелчок по заголовку колонки также меняет порядок и обновляет эти контролы, в том числе при группировке и фильтрации. Списки файла и проекта независимо сохраняют поле и направление сортировки в workbench.conf.

Урок: выберите строку исходника в списке файла, затем переключите стрелку, чтобы просмотреть объявления с конца файла. Выберите область видимости или путь файла в символах проекта для расположения связанных записей рядом. Сортировка не перемещает редактор и Контекст.


## Найти символ у курсора

Значок мишени рядом с контролами типов и команда «Найти символ у курсора» в контекстном меню списка показывают текущее объявление. Для поддерживаемых языков с фигурными скобками в буфере до 2 МиБ сначала ищется содержащая курсор индексированная функция; в остальных случаях выбирается ближайшее индексированное объявление, начинающееся на строке курсора или раньше. Границы функций по отступам эта команда не определяет.

Команда раскрывает свёрнутую группу и центрирует строку списка, не открывая исходник и не обновляя Контекст. Если предшествующего объявления нет, строка скрыта фильтром имени/типа или ещё не загружена, результат объясняется в строке состояния. Фильтры и объём загрузки остаются выбранными: уточните запрос или загрузите ещё строки и повторите. Список текущего файла должен закончить обновление перед выполнением команды.

Урок: поместите курсор внутрь C-функции, сверните её группу в списке и нажмите кнопку с мишенью. Строка функции появится, а редактор останется на месте. Затем отфильтруйте другое имя и повторите: фильтр сохранится, строка состояния объяснит, почему текущая функция не показана.


## Расположение колонок

Перетащите границу между заголовками, чтобы изменить ширину колонки. Перетащите заголовок по горизонтали, чтобы переместить колонку; щелчок сортирует список. Длинные значения сокращаются многоточием, список можно прокручивать по горизонтали. Панели файла и проекта независимо сохраняют ширины и порядок при сохранении настроек рабочей области. Группировка, фильтрация и дозагрузка сохраняют расположение колонок.

Команда «Восстановить колонки символов» в контекстном меню возвращает исходный порядок и ширины этой панели. Текущий запрос, фильтры типов, группировка и сортировка сохраняются. Старые настройки без расположения колонок используют стандартный вид; некорректные сохранённые значения игнорируются.

Урок: расширьте «Символ» и переместите «Строка» перед ним в панели файла. В панели проекта переместите «Файл» рядом с «Символ» и расширьте его. После перезапуска восстановится отдельное расположение каждой панели; через меню можно сбросить только одну из них.


## История фильтров

Значок истории рядом с полем имени открывает сохранённые запросы этой панели. Команда «Запомнить текущий фильтр символов» явно сохраняет запрос; Enter также сохраняет допустимый запрос перед обычной активацией результата. Сам набор текста не добавляет частичные запросы. Пустые запросы, одни пробелы и некорректные выражения исключаются; история принимает запросы до 256 байт UTF-8. Каждая панель хранит 16 последних различных запомненных запросов.

Выбор запроса меняет только фильтр имени и переносит фокус в него. Обычное обновление запроса сбрасывает порцию загруженных строк; категории типов, группировка, колонки и сортировка сохраняются. Результат не активируется. Текст запросов не переводится при смене языка интерфейса. Истории файла и проекта независимы и сохраняются в workbench.conf. Очистка истории очищает только историю этой панели, сохраняя текущий фильтр. При старте история восстанавливается, но последний запрос автоматически не применяется.

Урок: отфильтруйте семейство функций, откройте историю и запомните запрос. Попробуйте другое имя, затем выберите сохранённое семейство из истории. Список обновится, редактор останется на месте; нажмите Enter, когда потребуется открыть результат.
