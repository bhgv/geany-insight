# Устройство SPI на Lua

Добавьте правило в **Port Signals**. Относительный путь отсчитывается
от каталога исходника схемы. Короткая форма использует `sck cs_n mosi miso`
в режиме 0. В полной форме можно указать свои порты и активный нулём
сигнал сброса.

```text
spi-lua "spi-byte-queue.lua"
spi-lua sck other_cs_n mosi miso "spi-frame.lua" reset_n
```

Каждый экземпляр имеет собственное состояние Lua и поток ОС.
Переменные сохраняются между вызовами. Все функции необязательны.

| Функция | Поведение |
| --- | --- |
| `reset()` | Вызывается при запуске и сбросе. Сброс очищает очередь, Lua-скрипт сохраняет состояние и может сбросить свои переменные. |
| `shift(bit, index)` | Вызывается на каждом фронте SCK. Индекс от 0 до 7. Возврат 0 или 1 задаёт следующий бит MISO, nil оставляет управление очереди. |
| `receive(byte)` | Вызывается после каждого полного байта, включая байты, которыми ведущий тактирует ответ. |
| `finish(bytes)` | Вызывается при отпускании CS#. Таблица содержит только полные байты, начиная с индекса 1. |

`receive` и `finish` могут вернуть nil, один байт или несколько,
например `return 0x12, nil, 0x34`. Целые от 0 до 255 встают
в очередь в порядке возврата и сериализуются старшим битом вперёд.
Непереданные байты сохраняются между выборками CS#. При пустой
очереди выход передаёт FF. Очередь и кадр ограничены 4096 байтами.
