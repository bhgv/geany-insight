# Search Project и Lookup References

Две команды в меню поиска используют общую форму, но отдельные файлы настроек и истории. Кнопка Search Files в единой панели поиска и кнопка поиска проекта на toolbar открывают Search Project.

![Search command layout](../media/search-command-dialogs.svg)

- Запрос с историей до 32 записей; Lookup References подставляет слово или выделение из редактора.
- Область: проект, открытые документы, текущий файл, выбранные файлы/папка. Если список выбранных файлов пуст, Search открывает выбор файлов. Маски файлов сохраняются отдельно для каждой команды.
- Методы: текст, регулярное выражение GLib, Boolean/keyword и лексические ссылки на целый идентификатор. Регистр настраивается; метод ссылок включает Whole Words Only.
- Для keywords доступны варианты английских окончаний и расстояние 0–50 строк. Для фрагментов отключите Whole Words Only.
- Фильтр комментариев: весь текст, без комментариев, только комментарии, только код. Для неподдерживаемого языка отфильтрованный поиск пропускает файл.
- Search открывает общий Search Results; Enter, двойной щелчок или Ctrl+L переходят к совпадению; Alt+Up/Down просматривают его в Context.

Close тоже сохраняет параметры. Истории команд независимы. Изменённые открытые документы ищутся в памяти, без записи на диск. Сохраняются существующие ограничения движка: до 2 МиБ на файл, до 10000 файлов, до 2000 результатов.

Skip Inactive Code, Smart Reference Matching и Touch files показаны выключенными с пояснениями: они ещё не реализованы. Это не семантический поиск с разрешением перегрузок и не полная копия Source Insight. Обратные Source Links с отслеживанием правок пока отсутствуют.

Список выбранных файлов/папки общий с Search Results; запрос, история, область, маски и параметры каждой команды сохраняются раздельно.
