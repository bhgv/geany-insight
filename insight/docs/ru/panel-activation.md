# Активация панелей

**Вид → Панели → Активировать панель** содержит 15 команд: файлы, папки и символы проекта; Relations; закладки; Clips; типы файлов и категории символов; символы файла; Context; список окон; поиск в файле и проекте; результаты поиска; редактор исходника.

Команда показывает панель и выбирает её вкладку. Отсоединённое окно поднимается и восстанавливается после сворачивания в Tab Tray, сохраняя расположение. Повторная команда оставляет панель открытой. Фокус оказывается в фильтре, а для Context и результатов — в исходнике и списке. Команда редактора возвращает фокус текущему документу.

![Активация панели](../media/panel-activation.svg)

Назначьте сочетания в **Настройки → Комбинации клавиш → Фокус**. По умолчанию новые сочетания не назначены, существующие сохраняются. Команды также доступны через браузер команд.

Активация сохраняет запросы и фильтры, не запускает поиск и не подставляет выделенное слово. Поиск проекта показывает строку и страницу результатов даже до первого запроса. Исходный текст и история Undo не изменяются. Прежние переключатели видимости остаются доступны.
