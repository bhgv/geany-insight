# Быстрый поиск в файле

Поиск текста в текущем буфере без отдельного списка результатов. Откройте «Быстрый поиск в файле» через меню «Поиск/замена». Ctrl+F открывает штатный диалог поиска Geany.

## Управление

Поле поиска содержит запрос. Enter и «Следующее» находят следующее совпадение, «Предыдущее» — предыдущее. Параметры регистра, целого слова и регулярного выражения задают условия. Крестик или Escape скрывают строку. Кнопка «?» открывает эту страницу.

## Короткий урок

Откройте быстрый поиск, введите имя и нажмите Enter. Просмотрите совпадения кнопками следующего и предыдущего. Включите поиск целого слова, чтобы исключить более длинные имена, и закройте строку через Escape.
