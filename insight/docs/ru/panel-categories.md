# Категории символов

Языковой обзор символов индекса: классы, функции/методы, структуры, поля, переменные и другие типы. Название, цвет и значок берутся из общего native parser mapping; одна буква Ctags может означать разные типы в C++ и Python. Вложенные области показаны отдельными ветками.

В строке объявления класса/структуры/объединения/интерфейса можно раскрыть прямые индексированные члены его scope. Это дополнительное представление к обычным категориям: счётчик считает уникальные загруженные символы, не их повторные строки. При неоднозначных одноимённых объявлениях дополнительные члены не привязываются. Вывод типов, aliases, перегрузки и наследуемые члены здесь не разрешаются семантически.

## Управление

Общий фильтр символов принимает фрагменты, `~нечёткий`, `?regex`, точное имя в кавычках, `scope=` и `@путь`. Учитывается языковая область активного документа. Первые 5000 совпадений загружаются сразу; «Загрузить ещё» добавляет по 5000, до предела индекса 250000. Счётчик показывает загруженные / совпавшие уникальные символы. Новый запрос сбрасывает порцию. Все дополнительные строки членов подчиняются тому же запросу и загруженной порции.

Выбор объявления показывает Context. Двойной клик или Ctrl+Enter открывает определение; двойной клик группы переключает ветку. Правый клик открывает меню без навигации Context/редактора. Меню содержит открытие, Symbol Info, References, копирование имени/пути/расположения, точный фильтр выбранного имени, очистку, ветки, колонки, дозагрузку и справку. На заголовках групп исходные действия недоступны.

Колонки имени, scope, файла, строки и типа можно переставлять, изменять ширину и скрывать; имя обязательно. Колонки и сортировка сохраняются независимо от File Types. Обновление удерживает выбранную строку и раскрытые ветки по устойчивым идентификаторам; смена RU/EN обновляет названия категорий и счётчик.

Клавиши: Ctrl+F — фильтр, Ctrl+C — имя, Ctrl+Shift+C — путь:строка, Ctrl+Enter — открыть, Alt+Enter — Info, Menu/Shift+F10 — меню, Escape — редактор. В фильтре Down выбирает первую запись, Enter открывает, Escape очищает запрос перед возвратом фокуса. На macOS используется Primary. Неверный regex сохраняет предыдущий результат и блокирует открытие через Enter.

## Короткий урок

1. Раскройте «Классы», затем объявление класса и его прямые поля/методы.
2. Перейдите в «Функции»/«Методы», выберите запись и вызовите Alt+Enter.
3. Введите `~rn` или `scope=Widget`, проверьте счётчик.
4. При большом проекте нажмите «Загрузить ещё».
5. Настройте колонки и переключите RU/EN: выбранный символ не должен перемещать редактор.
