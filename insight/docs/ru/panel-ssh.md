# SSH

Удалённые файлы и команды через OpenSSH.

## Управление

Задайте сервер, пользователя, порт и ключ. Команды открывают удалённый файл, папку или проект; сохранение отправляет изменения. Stop останавливает передачу. Connect/Disconnect управляют оболочкой; ввод отправляется Enter, Ctrl+C прерывает команду. Это построчная оболочка, не полный эмулятор терминала.

## Короткий урок

Введите параметры своего сервера и подключитесь. Откройте известный удалённый файл. После правки явно сохраните его на сервере или включите автоматическую отправку.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [guide.md](guide.md).

## Обратная связь при подключении

Connect сначала запускает клиент OpenSSH, затем клиент проходит авторизацию на сервере. Запуск процесса не объявляется готовым подключением. Выделяемая строка состояния находится отдельно и переносится по ширине; ошибки запуска, отключения и коды завершения также остаются в тексте консоли. Причину сетевой ошибки или отказа сервера смотрите в исходном выводе клиента над ненулевым кодом завершения.

Клиенты из папки bin приложения запускаются по найденному абсолютному пути. Затем проверяется PATH, а в Windows — системные папки OpenSSH. Если помощник диалога пароля отсутствует, выводится сообщение о доступности только ключа/агента. Пароль и подтверждение ключа сервера запрашиваются в отдельном диалоге SSH. Пробелы вокруг адреса и логина игнорируются.

![SSH connection flow](../media/ssh-connection.svg)

SSH-панель разделена на вкладки справа: подключение, доступ к файлам и независимые терминалы. Кнопка «+» добавляет терминал (до 16); у каждого свой процесс, очередь ввода и журнал. Кнопку Ai с непрозрачностью 80% можно перетащить по терминалу; она открывает встроенного помощника. Используются общие профили моделей и проверяемые предложения правок через дифф. Явная кнопка выполнения отправляет предложенную команду только в этот терминал.


### Передача файлов отдельно от терминалов

Во вкладке Transfer задайте абсолютные локальный и удалённый пути, File/Folder и упаковку. Send отправляет, Receive получает; для получения укажите новое имя, существующие локальные файлы не перезаписываются. Без упаковки используется отдельный SCP; gz упаковывает один файл, tar.gz — файл или папку. При получении с упаковкой gzip/tar запускается на сервере через отдельный SSH без PTY. Архивы сохраняются как архивы, автоматической распаковки нет. Stop отменяет упаковку/передачу, сохраняя подключения терминалов.

Для локальной упаковки нужен Python 3, для удалённой — gzip/tar на сервере. SCP-пути на сервере ограничены буквами ASCII, цифрами и `/._-`, чтобы оставаться безопасными и на старых клиентах; для остальных имён используйте существующее открытие через SFTP. Перед отправкой проверьте имя назначения: удалённый файл может быть заменён.
