# Результат сведения

Редактируемый результат внутреннего двухстороннего сведения.

## Управление

Выберите различие и примите левую или правую версию блока. Результат можно править вручную. Undo/Redo отменяют и повторяют изменения; сохранение записывает выбранный файл результата.

## Короткий урок

Примите один блок слева, другой справа. Проверьте Undo и Redo. Просмотрите итог и сохраните результат в отдельный файл.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [internal-diff.md](internal-diff.md).
