# Список окон

Откройте Окно → Список окон…. Немодальное плавающее окно перечисляет живые документы редактора, включая безымянные. Оно не загружает дополнительные файлы проекта или дисковые предпросмотры Контекста.

Поиск сравнивает имена, полные пути и ближайшие распознанные символы с учётом Unicode-регистра. Столбцы показывают активность, имя, изменённость/только чтение, число строк, ближайший символ и путь. Заголовки сортируют; список порядка предлагает недавно использованные, имена и пути. Недавний порядок отслеживает открытие/активацию за сеанс.

Один выбор/клик показывает буфер на сохранённом месте курсора в Контексте; редактор остаётся на текущем документе. Двойной клик, Enter в поиске/списке или **Активировать** переключает буфер с сохранением курсора. Сохранение использует обычные действия Geany/Сохранить как. **Закрыть файл** использует запрос несохранённых правок: отмена оставляет буфер. Действия разрешают устойчивые ID при выполнении.

Видимый список обновляется после событий документов и редактора, объединяя обновления и сохраняя выбор по возможности. Escape скрывает окно; повторное открытие сохраняет поиск/сортировку. Крестик окна также скрывает список. Ближайший символ определяется тегами, не доказанной семантической областью. Флажок «Закрепить в боковой панели» переносит тот же список во вкладку боковой панели; снятие возвращает плавающее окно. Escape и крестик вкладки скрывают только список. Команда «Окно → Список окон…» показывает его снова. Режим сохраняется и используется при следующем вызове после перезапуска. Перетаскивание к произвольным краям, snap и включение списка в раскладки A–D остаются открытыми.

## Сохранение настроек окна

Перетаскивайте края столбцов для изменения ширины и заголовки для смены порядка.
Окно запоминает обычный размер/положение, развёрнутость, текст поиска, ширину и
порядок колонок, действующий столбец и направление сортировки (включая сортировку
заголовком). Настройки сохраняются по Escape, крестику, уничтожению вида и при
выходе из редактора; восстанавливаются при следующем создании списка, в том числе
после перезапуска. Сам список открывается только по команде.

Положение и обычный размер подгоняются под рабочую область монитора. Некорректные
размеры, ширины и параметры сортировки заменяются значениями по умолчанию; ошибочный
порядок столбцов игнорируется. Настройки записываются атомарно в
`config/insight/window-list.conf`. История активности конкретных буферов остаётся
частью текущего сеанса редактора. Переключение языка интерфейса обновляет статусы
файлов и информационную строку.

Начните фильтр с `~` для поиска Unicode-подпоследовательности (`~hlpr` находит `helper`). Обычный текст ищет подстроку без учёта регистра; запрос сохраняется при повторном открытии списка.
