# Открытые документы

Список буферов редактора.

## Управление

Выбор строки активирует документ. Контекстное меню предоставляет операции с открытыми файлами. Отдельное «Окно списка» добавляет фильтр и сортировку.

## Короткий урок

Откройте несколько файлов и переключитесь между ними через список. Для большого числа файлов откройте «Окно списка».

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [window-list.md](window-list.md).
