# Поиск и копирование списков

В контекстных меню **Символы файла**, **Символы проекта**, **Файлы проекта**, **Search Results** и обоих представлений списка/дерева **Relations** доступны:

| Команда | Действие |
| --- | --- |
| Copy List | Копирует все загруженные отфильтрованные строки в текущем порядке сортировки |
| Search List… | Открывает отдельное окно поиска по видимым колонкам |
| Next list match / F4 | Следующее совпадение после выбранной строки |
| Previous list match / Shift+F4 | Предыдущее совпадение перед выбранной строкой |

Поиск поддерживает буквальный текст Unicode, учёт регистра, регулярные выражения, начало списка и необязательный переход через край. Параметры и последний запрос сохраняются в памяти отдельно для каждой панели до её закрытия. F4 перехватывается только в поддерживаемом списке; в редакторе и терминале прежние клавиши сохраняются. Если запроса ещё нет, F4 открывает окно поиска.

Совпадение выделяется и прокручивается в видимую область; загруженные предки в дереве раскрываются. Файл в редакторе не открывается и его курсор не перемещается. Обычный предпросмотр Context при выборе строки сохраняется. Поиск не меняет фильтр, сортировку или состав проекта. В графе используйте список/дерево для этих команд.

Копия содержит заголовки и видимые колонки в их текущем порядке. Разделитель — табуляция, строки — LF, вложенность — два пробела на уровень. Табуляции, переводы строк, обратные косые черты и управляющие байты внутри ячейки экранируются (`\t`, `\n`, `\r`, `\\`, `\xNN`), поэтому одно значение не превращается в несколько колонок или строк. Скрытые колонки не попадают в копию или поиск.

## Пример

1. Отфильтруйте символы проекта, выберите сортировку и нужные колонки.
2. Откройте **Search List…**, введите имя или путь; для регулярного выражения включите соответствующий флажок.
3. Выберите **Find**, затем используйте F4/Shift+F4 в списке. Без флажка перехода через край поиск останавливается на границе.
4. Выберите **Copy List**, вставьте результат в документ или таблицу.

Обработка идёт короткими порциями в очереди GTK. При изменении модели, сортировки, состава/порядка/видимости колонок операция отменяется; поиск также отказывается менять выбор, если пользователь уже выбрал другую строку. Закрытие окна поиска отменяет ожидающий поиск. Новая команда заменяет ещё не законченную операцию. До полного успешного копирования буфер обмена остаётся прежним.

Пределы одной операции: 20 000 строк, 64 уровня дерева, 64 КиБ на строку/ячейку и 8 МиБ суммарного текста; запрос — 512 байт UTF-8. Регулярные выражения имеют дополнительные ограничения работы и глубины. При превышении лимита сузьте фильтр. Строки за пределами загруженной страницы, незагруженные ветви и исходники на диске не читаются. Это команды текущего списка, а не полный экспорт базы символов проекта.

В Search Results добавлено отдельное контекстное меню: щелчок правой кнопкой не меняет выбранный результат. Прежняя кнопка **Copy results** сохраняет формат диагностических строк; **Copy List** копирует видимые колонки с заголовками.
