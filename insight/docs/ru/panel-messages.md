# Сообщения

Общие сообщения Geany и результаты его штатных команд.

## Управление

Прокручивайте список и переходите по распознанным местам исходника. Результаты расширенного поиска Insight находятся в отдельной панели.

## Короткий урок

Прочитайте сообщение; если оно содержит распознанный файл и строку, активируйте его для перехода.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.
