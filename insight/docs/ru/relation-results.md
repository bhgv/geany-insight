# Результаты связей: текстовое дерево и пакет закладок

![Снимок загруженных связей](../media/relation-results.svg)

Команды **Навигация → Текстовое дерево связей…** и **Создать закладки из элементов связей…** доступны также по правой кнопке в Relations и через две кнопки-значка рядом с Поиск/Стоп.

Выделяемый предпросмотр только для чтения показывает запрос, режим, имена, пути и строки. Он учитывает фильтр и сортировку списка. Для дерева и его графа включаются уже материализованные ветви, отступы и сообщения о загрузке; неоткрытые ветви не подгружаются. **Обновить** явно заменяет снимок. **Копировать дерево** копирует его полностью. **Открыть дерево в буфере** создаёт новый редактируемый безымянный несохранённый документ, не заменяя исходник или существующий отчёт. При необходимости сохраните его обычной командой «Сохранить как».

**Создать закладки** использует показанные позиции и текущее глобальное/проектное хранилище закладок. Одинаковые абсолютные пути и строки, включая уже сохранённые закладки, пропускаются. Имена берутся из символов с уникальным номером; существующие имена и клипы сохраняются. Пустой пакет ничего не меняет.

Подготовка выполняется в фоне. Для открытых файлов берётся текущий текст, включая несохранённые правки. Закрытые файлы декодируются обычным чтением исходников без открытия вкладок редактора. В закладке сохраняется настоящая полная строка кода для существующего механизма переноса по текстовому якорю. Исходники, выделение, Undo и файлы на диске не редактируются. Закрытие диалога отменяет незавершённый пакет; уже созданные закладки остаются.

Перед записью проверяются снимок связей, проект/хранилище и его содержимое, идентификаторы/хеши открытых буферов и метаданные закрытых файлов. Устаревшие данные отклоняются: обновите и проверьте список снова. Существующая проверяемая запись хранилища сохраняет либо весь подготовленный пакет, либо прежнее состояние; конфликт файла сообщается. Это не блокировка файловой системы и не семантическое переопределение позиций устаревшего индекса.

Пределы: 2000 позиций исходников, 4000 просмотренных строк модели, 64 уровня дерева, 1 МиБ текста. Существующее хранилище вмещает 64 заметки, включая клипы при общем хранении; превышение свободной ёмкости отклоняет весь пакет. Снимки исходников ограничены 2 МиБ на файл и 16 МиБ суммарно, полная строка закладки — 64 КиБ. Безымянные/неабсолютные позиции и служебные сообщения нельзя сохранить как постоянные закладки. Режим текстового поиска использует отдельную панель Search Results: сначала выберите режим связей. Незагруженные потомки и семантически разрешённые вызовы не синтезируются.

Пример: найдите производные типы, отфильтруйте одну ветвь, просмотрите и создайте её закладки. Снимите фильтр и создайте остальные: прежние позиции будут пропущены. Раскройте ветвь дерева и нажмите «Обновить», чтобы включить её загруженных потомков.

Эталон Source Insight: [Create Bookmarks from Relation Items](https://www.sourceinsight.com/doc/v4/userguide/Manual/Command_Reference/Create_Bookmarks_from_Relation_Items.htm), [View Relation Outline](https://www.sourceinsight.com/doc/v4/userguide/Manual/Command_Reference/View_Relation_Outline.htm). Здесь реализован явный снимок в диалоге/буфере; полное совпадение с живым встроенным текстовым представлением и семантикой Source Insight не заявляется.
