# Символы проекта

Имена из индекса Ctags для проекта и совместимых языков.

## Управление

Фильтр ищет имена; сортировка доступна по имени, строке и типу. «Группировать по типу символа» создаёт раскрываемые группы. Цвет и значок обозначают тип: функции синие, типы фиолетовые, структуры бирюзовые, переменные зелёные, макросы янтарные. Выделение сохраняет читаемость системной темы. Информация о символе открывает подробности.

## Короткий урок

Переиндексируйте проект. Включите группировку и раскройте «Функции». Одиночным щелчком просмотрите определение в Контексте, двойным откройте строку в редакторе. Панель можно сузить, перетаскивая её левую границу вправо.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [symbol-info.md](symbol-info.md).


## Фильтр типов символов

Кнопка с воронкой открывает список категорий с флажками: функции/методы, типы/структуры, перечисления, константы перечислений, макросы, поля, переменные, локальные переменные, пространства имён/включения и прочие. Отмеченные категории остаются видимыми. «Показать все» сбрасывает ограничения; «Скрыть все» позволяет выбрать только нужные категории.

Фильтр работает вместе с поиском по имени и группировкой, не удаляет символы из индекса. Счётчик показывает число видимых записей и число записей, загруженных по фильтру имени. Настройки сохраняются отдельно для панели файла и панели проекта. Состав типов зависит от парсера языка; список ограничен первыми 2000 символами файла или 500 символами проекта, подходящими под запрос.

Урок: скройте всё, отметьте только функции/методы, найдите часть имени и включите группировку. Затем снимите ограничение командой «Показать все».
