# Символы проекта

Имена из индекса Ctags для проекта и совместимых языков.

## Управление

Фильтр ищет имена; сортировка доступна по имени, строке и типу. «Группировать по типу символа» создаёт раскрываемые группы. Цвет и значок обозначают тип: функции синие, типы фиолетовые, структуры бирюзовые, переменные зелёные, макросы янтарные. Выделение сохраняет читаемость системной темы. Информация о символе открывает подробности.

## Короткий урок

Переиндексируйте проект. Включите группировку и раскройте «Функции». Одиночным щелчком просмотрите определение в Контексте, двойным откройте строку в редакторе. Панель можно сузить, перетаскивая её левую границу вправо.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [symbol-info.md](symbol-info.md).
