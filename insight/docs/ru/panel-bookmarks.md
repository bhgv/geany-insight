# Закладки

Быстрый доступ к отмеченным строкам.

## Управление

Двойной щелчок по номеру строки ставит или снимает синий кружок. Кнопка с книжкой открывает список. В списке доступны переход, удаление, переименование, фильтр и импорт/экспорт.

## Короткий урок

Отметьте две строки. Откройте список кнопкой с книжкой. Щёлкните запись «файл:строка > текст», чтобы перейти в редакторе.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [context-bookmarks.md](context-bookmarks.md).

## Перенос проекта

При выбранном корне проекта/workspace экспорт закладок записывает файлы внутри корня относительными путями (формат notes v2). Перед импортом в перемещённую копию выберите её новый корень. Внешние файлы сохраняют абсолютные пути. Для относительных закладок импорт требует корень и отклоняет выход через `..`; совпадающие имена отклоняются, существующие заметки сохраняются. Старые снимки v1 читаются; обычное сохранение заметок и экспорт Clips остаются v1. Clips содержат текст/языковые привязки, а не пути источников. Список файлов проекта уже сохраняет внутренние пути относительно корня.

Начните фильтр списка с `~` для нечёткого поиска по Unicode-подпоследовательности без учёта регистра: `~srd` находит `Shared`. Обычный запрос ищет буквальную подстроку, включая пробелы и знаки. Один `~` ничего не находит.

## Восстановление относительно символа

Закладка запоминает ближайшее предыдущее объявление функции/класса (точное имя,
scope и вид) и смещение строки. После внешних правок она перемещается вместе с
объявлением, даже если на старом номере есть другой такой же текст. При
неоднозначном объявлении перенос останавливается. Если символ исчез, допустимо
только единственное совпадение текста; прежний номер строки не имеет приоритета.
Старые записи читаются. Привязка сохраняется при переименовании, выборе панели,
импорте/экспорте и переносе относительно корня проекта. Используется актуальное
поколение тегов; явный переход/закрытие может обновить теги буфера до 2 МиБ.
Движущиеся маркеры продолжают отслеживать обычные правки. Произвольные внешние
изменения внутри функции могут менять смысл смещения: это не семантическое
отслеживание изменений программы.

## Хранилище проекта и клавиатура

У каждого проекта свой файл `<имя проекта>.geany.bookmarks.conf` рядом с файлом
проекта. Пути внутри него записываются относительно корня исходников. Без
открытого проекта используется общий `insight/notes.conf`; общие шаблоны в нём
сохраняются независимо от закладок проектов. Это собственный INI-формат Geany
Insight, а не XML Source Insight.

Над списком показано активное хранилище. «Перечитать закладки» загружает внешние
изменения без предварительной перезаписи файла. Повреждённое хранилище не
заменяется пустым: запись блокируется до исправления и перечитывания. Если при
смене проекта не удалось сохранить перемещённые закладки, прежние данные остаются
в памяти; указано прежнее хранилище, редактирование блокируется. Их можно
экспортировать. Перечитывание с несохранёнными изменениями не уничтожает данные.

Столбцы показывают имя, файл, содержащий символ и строку. Поиск учитывает имя
символа. Существующая символьная привязка сохраняет смещение относительно
функции/класса при внешних изменениях; простой номер строки не гарантирует переход.

- Enter в пустом поле создаёт закладку A, B, …, Z, A1, B1, … без совпадений имён.
- Enter в списке или «Перейти» открывает выбранную закладку.
- Ctrl+N добавляет закладку или обновляет введённое имя.
- Ctrl+X удаляет выбранную закладку.
- Ctrl+O / Ctrl+S открывают импорт / экспорт закладок.

Изменение проекта во время открытого диалога отменяет запись в новое хранилище.
Неуспешное добавление, удаление или переименование сохраняет прежний список и
маркеры редактора. Импорт XML Source Insight пока не поддерживается: используется собственный формат.

## Выбор, сохранение и удаление нескольких закладок

Ctrl+щелчок выбирает отдельные строки, Shift+щелчок — диапазон. Ctrl+A выбирает
все видимые строки. Delete или Ctrl+X удаляет выбранные закладки одной записью:
при ошибке записи сохраняются список, выделение и маркеры редактора. Фильтрация
и обновление сохраняют выбранные имена, которые остаются видимыми.

**Экспортировать выбранные…** и Ctrl+S сохраняют только выбранные строки.
Без выделения экспорт не начинается. Правый щелчок или Menu/Shift+F10 открывает
меню со значками: переход, переименование, пакетное удаление, импорт, экспорт
выбранных, **Экспортировать все закладки…**, выбор всех и снятие выделения.
Экспорт всех включает закладки, скрытые фильтром; Ctrl+A выбирает только видимые.
Переименование требует одной строки. При множественном выборе Enter открывает
выбранную строку с курсором. Правый щелчок по уже выбранной строке сохраняет
группу и не переводит редактор в другое место.

Экспорт фиксирует выбранные записи до открытия диалога, включая символьные
привязки и переносимые пути. Смена проекта/хранилища в открытом диалоге отменяет
экспорт. Clips по-прежнему экспортирует всю панель. Используется собственный
формат Geany Insight (`.conf`), а не XML Source Insight.

## Команды поля и подтверждение удаления

Enter в поле открывает закладку с точным именем. Уникальное частичное имя тоже
открывает закладку; при нескольких совпадениях нужно выбрать строку. Десятичное
число переводит редактор на строку с этим номером, считая от 1. Существующая
закладка с точно таким числовым именем имеет приоритет. Ноль и номер вне файла
вызывают сообщение без создания закладки. Несовпавшее нечисловое имя создаёт
закладку в текущем месте редактора. Пустое поле сохраняет автоматические имена
A/B/…; Enter в списке по-прежнему открывает выбранную строку.

Меню списка содержит **Удалить все закладки…**, включая скрытые фильтром.
Команда всегда запрашивает подтверждение, по умолчанию выбрана отмена. Удаляются
только закладки активного хранилища; шаблоны и исходные файлы сохраняются.
**Подтверждать удаление закладок** в том же меню включает подтверждение также
для Delete/Ctrl+X выбранных строк. Настройка сохраняется между запусками; для
прежних профилей она выключена. Отмена, перечитывание хранилища/смена проекта
в открытом подтверждении и ошибка записи не применяют запрошенное удаление.
Удаление при закрытии файла и общий диалог параметров описаны ниже.
Политика сохранения между сеансами описана ниже.

## Шрифт и цвет панели

В меню списка закладок (правый щелчок или Menu / Shift+F10) выберите
«Шрифт и цвет…». Включите «Использовать свои настройки оформления», задайте
шрифт размером 4–96 пунктов, цвет текста и фона, затем нажмите «Применить».
«Отмена» оставляет прежнее оформление. Отключение своих настроек возвращает
оформление текущей темы; выбранные шрифт и цвета сохраняются для повторного
включения. Настройка применяется ко всем столбцам панели и сохраняется между
запусками независимо от Project Folders и Browse disk. Цвета выделения задаёт
тема. Настройка относится к панели Bookmarks, а не к отдельному списку закладок
редактора, открываемому кнопкой с книгой.

## Удаление при закрытии файла

В меню панели включите «Удалять закладки при закрытии файла». По умолчанию
настройка выключена и сохраняется между запусками. При включении закрытие
файла удаляет все его закладки из активного хранилища, включая скрытые фильтром.
Закладки других файлов и Clips сохраняются. Подтверждение ручного удаления
не применяется к этой автоматической операции. Отмена закрытия изменённого
файла не удаляет закладки. При ошибке записи прежний список остаётся в памяти;
закладки можно восстановить при повторном открытии файла. Настройка не очищает
закладки при обычном выходе с сохранением сеанса.

## Диалог параметров закладок

Кнопка «Параметры закладок…» в панели и одноимённая команда меню открывают
общий диалог. Ctrl+Q вызывает его, когда фокус находится в поле или списке
закладок; в остальных областях сочетание сохраняет обычное назначение Geany.
Флажки подтверждения удаления и удаления при закрытии файла применяются вместе
по кнопке «Применить» и сразу сохраняются. «Отмена» оставляет прежние значения.
При ошибке записи диалог остаётся открытым, а действующие параметры не меняются.

Кнопка «Шрифт и цвет…» открывает отдельный диалог оформления с собственными
«Применить» и «Отмена»; отмена параметров закладок не отменяет уже применённое
оформление. Кнопка справки открывает эту страницу. Флажок сохранения между сеансами
описан ниже.

## Сохранять закладки между сеансами

В «Параметрах закладок…» включён одноимённый флажок. Для прежних профилей
поведение сохраняется: закладки восстанавливаются после перезапуска. Если
выключить флажок и нажать «Применить», закладки остаются доступны до завершения
работы, в том числе при закрытии и повторном открытии проекта. При обычном
выходе очищаются закладки глобального хранилища и всех проектов, использованных
в этом сеансе. Отмена выхода не очищает их. Повторное включение флажка до выхода
сохраняет закладки. Удаление при закрытии файла действует независимо от него.

Clips, языковые привязки шаблонов, файлы ручного экспорта и исходники сохраняются.
Хранилища проектов, не открывавшихся в этом сеансе, не обходятся. Перед очисткой
проверяются сохранённый снимок содержимого и метка версии файла. Изменившееся
извне, повреждённое или недоступное для записи хранилище остаётся на диске;
ошибка выводится в журнал. При аварийном завершении очистка не выполняется,
поэтому ранее автоматически записанные закладки могут восстановиться.
