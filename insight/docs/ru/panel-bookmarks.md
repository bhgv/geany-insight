# Закладки

Быстрый доступ к отмеченным строкам.

## Управление

Двойной щелчок по номеру строки ставит или снимает синий кружок. Кнопка с книжкой открывает список. В списке доступны переход, удаление, переименование, фильтр и импорт/экспорт.

## Короткий урок

Отметьте две строки. Откройте список кнопкой с книжкой. Щёлкните запись «файл:строка > текст», чтобы перейти в редакторе.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [context-bookmarks.md](context-bookmarks.md).
