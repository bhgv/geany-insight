# Закладки

Быстрый доступ к отмеченным строкам.

## Управление

Двойной щелчок по номеру строки ставит или снимает синий кружок. Кнопка с книжкой открывает список. В списке доступны переход, удаление, переименование, фильтр и импорт/экспорт.

## Короткий урок

Отметьте две строки. Откройте список кнопкой с книжкой. Щёлкните запись «файл:строка > текст», чтобы перейти в редакторе.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [context-bookmarks.md](context-bookmarks.md).

## Перенос проекта

При выбранном корне проекта/workspace экспорт закладок записывает файлы внутри корня относительными путями (формат notes v2). Перед импортом в перемещённую копию выберите её новый корень. Внешние файлы сохраняют абсолютные пути. Для относительных закладок импорт требует корень и отклоняет выход через `..`; совпадающие имена отклоняются, существующие заметки сохраняются. Старые снимки v1 читаются; обычное сохранение заметок и экспорт Clips остаются v1. Clips содержат текст/языковые привязки, а не пути источников. Список файлов проекта уже сохраняет внутренние пути относительно корня.

Начните фильтр списка с `~` для нечёткого поиска по Unicode-подпоследовательности без учёта регистра: `~srd` находит `Shared`. Обычный запрос ищет буквальную подстроку, включая пробелы и знаки. Один `~` ничего не находит.
