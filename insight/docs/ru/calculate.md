# Вычисления и состояние файла

**Правка → Вычисления → Вычислить выделение** вычисляет точное обычное выделение и заменяет его результатом одним действием отмены. Например, `112*14` превращается в `1568`. Поддерживается обратное выделение; окружающий Unicode-текст и окончания строк сохраняются. Ошибка не меняет текст; совпадающий результат не добавляет действие Undo. Требуется доступное для записи выделение.

![Рабочий диалог в изолированной GUI-проверке Linux](../media/calculate.jpg)

![Действия калькулятора](../media/calculate.svg)

**Калькулятор…** открывает многострочное поле, заполненное поддерживаемым выделением либо пустое. «Вычислить» показывает результат, «Копировать результат» пересчитывает и копирует его, «Вставить результат» пересчитывает и заменяет исходное выделение либо вставляет в позицию курсора, где было открыто окно. При режиме чтения и неподдерживаемом выделении доступны вычисление/копирование, а вставка выключена. Изменение выражения очищает прошлый результат. Исходный код и команды не выполняются.

Поддерживаются десятичные числа с точкой и экспоненты: `.5`, `2.`, `1.5e-3`. Операторы: `+ - * / % ^`, скобки, унарные знаки. Степень `^` правоассоциативна: `2^3^2 = 512`, `-2^2 = -4`, `2^-2 = 0.25`. `%` вычисляет остаток с плавающей точкой. Константы: `pi`, `e`. Разрешённые функции:

| Один аргумент | Два аргумента через запятую |
| --- | --- |
| `abs sqrt floor ceil round sin cos tan log exp` | `min max pow` |

Тригонометрия использует радианы; `log` — натуральный логарифм; `round` округляет половинные случаи от нуля. Регистр имён важен. Присваивание, переменные, неявное умножение, шестнадцатеричные/двоичные литералы, побитовые операции, комментарии и произвольный код не поддерживаются.

Используется приближённая двойная точность IEEE (около 15–17 значащих десятичных цифр), без точных больших целых, произвольной точности и десятичной бухгалтерской арифметики. Большие целые могут округляться; `1/3` выводится как `0.33333333333333331`. Формат результата с точкой не зависит от локали и сохраняет значение double при повторном чтении; отрицательный ноль становится `0`. Нулевой делитель, бесконечность/NaN, ошибки области/диапазона функций и недопустимые литералы отклоняются. Ограничения: UTF-8 без NUL до 4096 байт, 64 уровня вложенности, 2048 значений/операторов. Смещения ошибок — байты с нуля.

Перед вставкой повторно проверяются документ, поколение правок, точное выделение, активная вкладка и доступность записи. Изменение текста/выделения, переключение или закрытие вкладки отменяют вставку. Целью может быть одно обычное выделение; прямоугольные/множественные выделения и виртуальные пробелы исключены. Прямая команда сохраняет буфер обмена; окно меняет его только кнопкой копирования. История выражений/результатов не сохраняется.

## Состояние файла

**Файл → Показать состояние файла** выводит имя текущего буфера, число строк Scintilla, число байт UTF-8, состояние изменений и доступность записи в штатную строку состояния и журнал сообщений Status. Учитывается текущий текст, включая несохранённые правки; чтения или записи файла на диске нет. Пустой буфер считается одной строкой, конечный перевод строки оставляет пустую строку EOF. Текст, курсор, выделение и Undo не меняются. После смены языка следующий отчёт использует новый язык.
