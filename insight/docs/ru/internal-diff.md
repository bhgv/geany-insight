# Внутреннее сравнение и сведение

Откройте **Инструменты → Сравнение / Сведение…**, кнопку двух колонок на панели или команду в заголовке Контекста. Выберите левый и правый файлы и нажмите **Сравнить**. Немодальное окно показывает два исходника только для чтения, подсвечивает изменённые строки и перечисляет блоки различий. Выбор блока прокручивает к нему все три области.

Редактируемый результат изначально содержит левый файл. **Принять слева / Принять справа** заменяет выбранный блок; любую сторону можно повторно выбирать. Пустые блоки представляют вставку или удаление. Результат можно редактировать вручную.

**Отменить / Повторить**, Ctrl+Z / Ctrl+Shift+Z / Ctrl+Y охватывают замену блоков и ручные изменения. Замена блока — одна операция истории. Правка после отмены удаляет ветку повтора. Метки результата перемещаются с изменениями и восстанавливаются с историей.

История использует полные снимки и ограничена примерно 32 МиБ; последний снимок сохраняется всегда. **Сохранить результат…** выбирает файл назначения и подтверждает перезапись. Закрытие или новое сравнение спрашивает перед отбрасыванием изменённого результата. Исходники автоматически не сохраняются.

**Внешний KСравнение3 (необязательно)** явно запускает `kdiff3` из PATH с двумя выбранными файлами, в том числе когда встроенное сравнение превышает ограничения. Автоматического запуска нет. Отсутствие KСравнение3 не влияет на внутренний инструмент. Его внешние правки имеют отдельную историю.

Начальная версия: двухстороннее построчное сравнение и ручное сведение текста UTF-8 без нулевых байтов, до 1 МиБ на исходник. Сохраняются CRLF и различия последнего перевода строки. Независимый движок LCS обрезает общие начало/конец и ограничивает матрицу 4 миллионами ячеек. Пока нет трёхстороннего сведения по общей базе, автоматического разрешения конфликтов, внутристочной подсветки и синхронной прокрутки.

Если ручная правка убрала несколько границ блоков, повторите сравнение для перестроения списка. Список описывает исходные файлы, а не новое сравнение результата.

Проверка ядра: `python3 insight/tests/diff_test.py` (нужен компилятор C99). Meson и Autotools включают окно в нативную сборку; требуются заголовки GTK.
