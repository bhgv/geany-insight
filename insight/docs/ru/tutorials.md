# Geany Insight: практические уроки

В каждом уроке указан путь к команде и ожидаемый результат. Начните с небольшой копии своего проекта, чтобы свободно менять текст и проверять Undo.

## Урок 1. Найти определение, не потеряв место

1. Откройте проект и дождитесь индексации.
2. Поставьте курсор на вызов функции в основном редакторе. Контекст покажет известное определение.
3. Нажмите на другое имя внутри Контекст один раз. Основной редактор должен остаться на прежней строке, а Контекст перейдёт к определению этого имени.
4. Дважды нажмите на нужную строку в Контекст. Теперь основной редактор откроет этот файл и центрирует строку.
5. Для просмотра предыдущего места нажмите Назад в контексте. Для обычного перехода из редактора используйте F12.

Если определение не найдено, проверьте, входит ли файл в проект, и выполните Переиндексировать рабочую папку. Не все обращения разрешаются лексическим индексом.

## Урок 2. Собрать список важных строк

1. Дважды нажмите на номер строки. Синий кружок слева означает закладку.
2. Поставьте ещё одну закладку в другом файле.
3. Нажмите на панели книжку с закладкой. В немодальном окне видны обе записи с текстом строк.
4. Выберите запись. Редактор откроет нужный файл и строку.
5. Дважды нажмите на её номер строки, чтобы убрать закладку.

## Урок 3. Поиск в файле и замена с Undo

1. Ctrl+F открывает поиск в текущем документе. Введите имя, найдите следующее совпадение и закройте окно.
2. Ctrl+H открывает замену. Укажите старый и новый текст, проверьте параметры регистра и Регулярное выражение.
3. Сначала замените одно совпадение и проверьте результат.
4. Ctrl+Z отменяет сделанную правку редактора; Ctrl+Y возвращает её при стандартных настройках Geany.
5. Компактный поиск доступен через Поиск/замена → Быстрый поиск в файле…. Escape закрывает его строку.

Если ваши горячие клавиши переназначены в настройках Geany, используйте команды меню или кнопки панели.

## Урок 4. Поиск по проекту или папке

1. Нажмите кнопку Поиск в проекте / папке / открытых файлах либо Поиск/замена → Поиск в проекте….
2. Введите запрос. Для проекта оставьте Файлы проекта; для открытых буферов выберите Открытые документы.
3. Для внешней папки выберите Поиск в папке… и укажите папку. Маска `*.c;*.h` оставит C-исходники и заголовки.
4. Нажмите Search. Один выбор результата показывает только Контекст; Enter открывает совпадение в редакторе.
5. Alt+Вниз просматривает следующее совпадение без перехода редактора. Остановить завершает длительный поиск.
6. Закройте Результаты поиска крестиком. При следующем вызове запроса и результатов окно появится снова.

Папочный поиск пропускает скрытые каталоги, node_modules, __pycache__ и файлы больше 2 MiB. Для больших входов используйте отдельный инструмент или разбейте набор.

## Урок 5. Разобраться в символе

1. Поставьте курсор на имя и вызовите Навигация → Сведения о символе….
2. Просмотрите тип, область, файл и код. При нескольких кандидатах смените запись в выпадающем списке.
3. Оставить файл открытым загрузит закрытый файл, сохранив текущий редактор активным.
4. Использования переключит на отношения и поиск имени по проекту.
5. В Связи смените Список на Граф. Выберите узел для Контекст; двойной клик открывает редактор.
6. Измените масштаб или направление графа. D, C и R выполняют запросы определений, вызовов и употреблений выбранного символа, когда граф имеет фокус.

## Урок 6. Свести два файла

1. Откройте Инструменты → Сравнение / Сведение… кнопкой с двумя колонками.
2. Выберите две версии небольшого текстового файла.
3. Перейдите к отличию и возьмите нужную сторону в результат.
4. Отредактируйте результат вручную, если ни одна сторона не подходит целиком.
5. Используйте Undo и Redo внутри окна сведения.
6. Сохраните результат под отдельным именем и проверьте его в редакторе.

Это двухстороннее сведение. Автоматическое трёхстороннее сведение по общей базе пока не предоставляется встроенным инструментом.

## Урок 7. Написать свою команду

Следуйте [первому Lua-расширению](scripting.md). Оно оборачивает выделение в скобки, появляется в Скрипты → Команды и вызывается Ctrl+Alt+W. Изменения отменяются Undo. Справочник методов — [Lua API](lua-api.md).

## Урок 8. Сделать собственную справку

1. Создайте UTF-8 файл `notes.md` с заголовком `# Мои заметки`, ссылкой и изображением `![Схема](scheme.png)`.
2. Положите `scheme.png` рядом с ним.
3. Откройте Справка → Просмотр Markdown / reStructuredText… и выберите `notes.md`.
4. Для GIF используйте ту же запись; анимация воспроизводится в компактном просмотре.
5. Для видео используйте `![Демонстрация](demo.webm)` и откройте Multimedia view. В браузере появятся элементы воспроизведения видео.
6. Измените файл в редакторе и сохраните. В просмотрщике нажмите Обновить документ.

[Подробнее о Markdown, reStructuredText и мультимедиа](markup-viewer.rst).

## Предпросмотр собственной страницы

1. Создайте документ Markdown или reStructuredText и добавьте несколько заголовков.
2. Нажмите кнопку страницы на главной панели или Справка → Предпросмотр текущего Markdown / RST…. Несохранённый текст сразу появится в отдельном окне.
3. Выберите заголовок в оглавлении. Нажмите Ctrl+F, введите слово; F3 и Shift+F3 переходят между совпадениями. Escape закрывает поиск.
4. Измените текст редактора и нажмите Обновить документ в просмотрщике. Для относительных картинок сохраните документ рядом с ними; GIF показывается с анимацией.
5. Для видео используйте Multimedia view. Это открывает текущий предпросмотр в браузере с элементами управления видео.

Шаблоны кода с примером и переменными описаны в [Закладки и шаблоны](context-bookmarks.md#шаблоны-кода).
