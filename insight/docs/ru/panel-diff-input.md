# Входные файлы сравнения

Левая и правая исходные версии для внутреннего Diff/Merge.

## Управление

Выберите два входных файла. Подсветка показывает различающиеся строки. Исходные панели служат для чтения; изменение результата выполняется в панели сведения. Внешний KDiff3 запускается только отдельной необязательной командой.

## Короткий урок

Откройте Diff/Merge в «Инструментах» или главной панели, выберите две версии и перейдите к различию.

Кнопка «?» справа вверху открывает эту страницу. Язык справки следует настройке интерфейса в Options.

Подробнее: [internal-diff.md](internal-diff.md).
