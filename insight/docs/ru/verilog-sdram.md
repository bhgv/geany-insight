# Тестовое устройство SDR SDRAM

В **Port Signals** правило `sdram` подключает встроенную SDR SDRAM x16.
Порты по умолчанию идут в порядке `ck cke cs_n ras_n cas_n we_n a ba dq dqm`.
Для других имён перечислите порты в том же порядке. Адрес A занимает
13 бит, BA и DQM — по 2 бита, двунаправленная шина DQ — 16 бит.

```text
module my_controller
memory-image a "fixtures/sdram.hex"
sdram
```

Необязательный hex-образ содержит 16-битные слова. Адрес слова
вычисляется по формуле `(row << 11) | (bank << 9) | column`.
Например, `@c04 beef` задаёт слово в строке 1, банке 2, столбце 4.
Незаписанные слова читаются как X. Геометрия модели — 4 банка по
8192 строки и 512 столбцов. За сеанс хранится до 65 536 разных слов.

При запуске действуют BL1 и CAS 3. Команда LOAD MODE REGISTER
задаёт последовательный пакет BL1/2/4/8, CAS 2/3 и, при необходимости,
одиночную запись. Поддерживаются ACTIVATE, READ, WRITE, PRECHARGE,
автопредзаряд и BURST TERMINATE. Первый такт записи совпадает с
командой WRITE. DQM маскирует байты записи сразу, а байты чтения
через два разрешённых такта. Модель обслуживает один пакет за раз.
Регенерация, режимы питания и физические тайминги находятся за рамками
этой функциональной модели.
