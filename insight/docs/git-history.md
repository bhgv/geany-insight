# История Git и дифф только для чтения

Откройте **Файл → История Git и сравнение…** для текущего проекта. Если проект не открыт, используется репозиторий текущего сохранённого файла. Нужен установленный Git. Команда **История Git и сравнение** также есть в браузере команд; сочетание клавиш в группе Editor изначально не назначено.

Выберите **HEAD**, локальную ветку или локально сохранённую удалённую ветку. В списке коммитов показаны короткий идентификатор, тема, автор и дата автора. При выборе загружаются полный идентификатор, автор, дата, всё сообщение коммита и список изменённых файлов. **Более новый / Более старый коммит** перемещают выбор в текущей странице; работают и стрелки списка. **Предыдущая / Следующая страница** показывают по 200 коммитов. Конец ветки фиксируется идентификатором объекта; **Обновить** перечитывает ветки и открывает начало выбранной истории.

У merge-коммита можно выбрать родителя для сравнения. Корневой коммит сравнивается с пустой версией. Выбор файла автоматически загружает его историческое содержимое: слева родитель, справа выбранный коммит. У добавленного или удалённого файла противоположная сторона пуста. Переименования пока показаны удалением и добавлением. Изменение режима файла попадает в список даже при одинаковом тексте. Для подмодуля показан сохранённый идентификатор коммита, для символической ссылки — текст её цели без перехода по ссылке.

Оба окна кода — **Scintilla только для чтения**: подсветка синтаксиса выбирается по историческому имени файла, видны номера строк и цветной фон изменённых строк. Текст можно выделять и копировать. Список различий показывает начальные номера строк с единицы; кнопки **Предыдущее / Следующее различие** выделяют соответствующие диапазоны и прокручивают оба окна. На пустой стороне вставки или удаления используется якорь. Сравнение точное, включая пробелы и окончания строк, на существующем ядре Diff/Merge. Применения, слияния и сохранения в этом окне нет.

Загрузка выполняется отменяемыми фоновыми задачами. Смена ветки, коммита, родителя или файла отменяет предыдущую задачу; устаревший результат не подменяет новый выбор. **Отменить загрузку** останавливает текущий запрос; новый выбор или Обновить продолжает просмотр. Закрытие отменяет незавершённую работу.

Просмотр не переключает ветку рабочей копии, не добавляет файлы в индекс, не создаёт коммиты, не сохраняет несохранённые документы и не изменяет файлы на диске. Объекты читаются по полным идентификаторам без оболочки, внешнего diff/textconv, пейджера и фонового скачивания отсутствующих объектов. Недоступный объект или репозиторий обозначается в строке состояния. Удалённые ветки показаны по локальным refs; сетевой fetch не выполняется. Комментарий здесь — сообщение самого коммита; комментарии ревью GitHub не загружаются.

Поддержан UTF-8 без NUL до 1 МиБ на сторону. Для бинарного, другого кодирования или слишком большого файла выводится причина недоступности текстового диффа. Дополнительные пределы: 1000 веток, 10000 изменённых файлов, 64 КиБ сообщения коммита, пропуск до 100000 коммитов и 4 миллиона ячеек двухстороннего LCS. Слишком большие списки отклоняются явно. Теги, поиск истории, произвольная пара ревизий, blame и граф коммитов пока не реализованы.

См. [Проекты Git](panel-project-git.md), [Diff / Merge](internal-diff.md), [сравнение снимков](snapshot-comparison.md). Форматы команд: официальные [log](https://git-scm.com/docs/git-log), [diff-tree](https://git-scm.com/docs/git-diff-tree), [cat-file](https://git-scm.com/docs/git-cat-file).
