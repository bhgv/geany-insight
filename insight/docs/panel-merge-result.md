# Merge result

The editable result of internal two-way merging.

## Controls

Select a difference and take its left or right block. Edit the result manually if needed. Undo/Redo reverses and reapplies changes; Save writes the selected output file.

## Short tutorial

Take one block from the left and another from the right. Check Undo and Redo. Review the result and save it to a separate file.

The ? button at the upper right opens this page. Help follows the interface language selected in Options.
