# Geany Insight: практические уроки

В каждом уроке указан путь к команде и ожидаемый результат. Начните с небольшой копии своего проекта, чтобы свободно менять текст и проверять Undo.

## Урок 1. Найти определение, не потеряв место

1. Откройте проект и дождитесь индексации.
2. Поставьте курсор на вызов функции в основном редакторе. Context покажет известное определение.
3. Нажмите на другое имя внутри Context один раз. Основной редактор должен остаться на прежней строке, а Context перейдёт к определению этого имени.
4. Дважды нажмите на нужную строку в Context. Теперь основной редактор откроет этот файл и центрирует строку.
5. Для просмотра предыдущего места нажмите Context back. Для обычного перехода из редактора используйте F12.

Если определение не найдено, проверьте, входит ли файл в проект, и выполните Reindex workspace. Не все обращения разрешаются лексическим индексом.

## Урок 2. Собрать список важных строк

1. Дважды нажмите на номер строки. Синий кружок слева означает закладку.
2. Поставьте ещё одну закладку в другом файле.
3. Нажмите на панели книжку с закладкой. В немодальном окне видны обе записи с текстом строк.
4. Выберите запись. Редактор откроет нужный файл и строку.
5. Дважды нажмите на её номер строки, чтобы убрать закладку.

## Урок 3. Поиск в файле и замена с Undo

1. Ctrl+F открывает поиск в текущем документе. Введите имя, найдите следующее совпадение и закройте окно.
2. Ctrl+H открывает замену. Укажите старый и новый текст, проверьте параметры регистра и Regex.
3. Сначала замените одно совпадение и проверьте результат.
4. Ctrl+Z отменяет сделанную правку редактора; Ctrl+Y возвращает её при стандартных настройках Geany.
5. Компактный поиск доступен через Поиск/замена → Quick find in file…. Escape закрывает его строку.

Если ваши горячие клавиши переназначены в настройках Geany, используйте команды меню или кнопки панели.

## Урок 4. Поиск по проекту или папке

1. Нажмите кнопку Search project / folder / open files либо Поиск/замена → Search project….
2. Введите запрос. Для проекта оставьте Project files; для открытых буферов выберите Open documents.
3. Для внешней папки выберите Search folder… и укажите папку. Маска `*.c;*.h` оставит C-исходники и заголовки.
4. Нажмите Search. Один выбор результата показывает только Context; Enter открывает совпадение в редакторе.
5. Alt+Down просматривает следующее совпадение без перехода редактора. Stop завершает длительный поиск.
6. Закройте Search Results крестиком. При следующем вызове запроса и результатов окно появится снова.

Папочный поиск пропускает скрытые каталоги, node_modules, __pycache__ и файлы больше 2 MiB. Для больших входов используйте отдельный инструмент или разбейте набор.

## Урок 5. Разобраться в символе

1. Поставьте курсор на имя и вызовите Navigate → Symbol Info….
2. Просмотрите тип, область, файл и код. При нескольких кандидатах смените запись в выпадающем списке.
3. Leave file open загрузит закрытый файл, сохранив текущий редактор активным.
4. References переключит на отношения и поиск имени по проекту.
5. В Relations смените List на Graph. Выберите узел для Context; двойной клик открывает редактор.
6. Измените масштаб или направление графа. D, C и R выполняют запросы определений, вызовов и употреблений выбранного символа, когда граф имеет фокус.

## Урок 6. Свести два файла

1. Откройте Tools → Diff / Merge… кнопкой с двумя колонками.
2. Выберите две версии небольшого текстового файла.
3. Перейдите к отличию и возьмите нужную сторону в результат.
4. Отредактируйте результат вручную, если ни одна сторона не подходит целиком.
5. Используйте Undo и Redo внутри окна сведения.
6. Сохраните результат под отдельным именем и проверьте его в редакторе.

Это двухстороннее сведение. Автоматическое трёхстороннее сведение по общей базе пока не предоставляется встроенным инструментом.

## Урок 7. Написать свою команду

Следуйте [первому Lua-расширению](scripting.md). Оно оборачивает выделение в скобки, появляется в Scripts → Commands и вызывается Ctrl+Alt+W. Изменения отменяются Undo. Справочник методов — [Lua API](lua-api.md).

## Урок 8. Сделать собственную справку

1. Создайте UTF-8 файл `notes.md` с заголовком `# Мои заметки`, ссылкой и изображением `![Схема](scheme.png)`.
2. Положите `scheme.png` рядом с ним.
3. Откройте Help → Markdown / reStructuredText viewer… и выберите `notes.md`.
4. Для GIF используйте ту же запись; анимация воспроизводится в компактном просмотре.
5. Для видео используйте `![Демонстрация](demo.webm)` и откройте Multimedia view. В браузере появятся элементы воспроизведения видео.
6. Измените файл в редакторе и сохраните. В просмотрщике нажмите Reload document.

[Подробнее о Markdown, reStructuredText и мультимедиа](markup-viewer.rst).
