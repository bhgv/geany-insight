# Context and bookmarks

Single click on a symbol in Context follows its definition inside Context only. Double click on a code line opens the currently previewed file at that line in the editor and centers the caret vertically. Single-click navigation waits for the system double-click interval so it cannot redirect the double click.

Double click on an editor line number toggles its bookmark. A blue circle appears to the left of the number. The book icon in the toolbar opens a nonmodal searchable list: `filename:line> text`. Selecting a row opens that line in the editor. Scintilla markers follow inserted and deleted lines; named bookmarks are persisted with source anchors.

Open internal comparison from Tools → Diff / Merge…. External KDiff3 is optional and only runs when its button is clicked.

## Обзор файла и переходы по правкам

Миниатюра **Вид → Обзор** (Overview) показывает файл справа от редактора.
Синие кружки слева обозначают закладки. Оранжевая полоса справа обозначает
несохранённые правки, зелёная — правки, уже сохранённые в текущем сеансе файла.
После закрытия и повторного открытия файла история изменений начинается заново.
Удаление текста отмечается на оставшейся строке рядом с местом удаления.
Метки обновляются при Undo/Redo; закладки перемещаются вместе с текстом.

**Правка → Следующее несохранённое изменение** (`Alt+Num +`) и
**Предыдущее несохранённое изменение** (`Alt+Num -`) переходят между отдельными
блоками изменённых строк. Клавиши +/− относятся к цифровому блоку клавиатуры.
Команды также доступны по правому клику на миниатюре. Переход пропускает текущий
блок, не делает круг по файлу и не меняет его содержимое; сохранённые изменения
не участвуют. Переходы поддерживают файлы до 2 МиБ.

Правый клик → **Параметры обзора…** включает и выключает закладки, изменения,
сохранённые изменения и подсказки при наведении. Подсказка содержит номер и текст
строки, состояние правки и наличие закладки. Эти параметры сохраняются между
запусками. Обзор рисует только отметки строк, видимых в миниатюре.
Настройка отметок в левом поле основного редактора остаётся отдельной.

### Границы функций в обзоре

В **Параметрах обзора…** доступны **Показывать границы текущей функции**
и **Показывать границы всех функций**. Текущая функция, целиком содержащая
курсор или выделение, обведена фиолетовой рамкой; остальные — серыми рамками.
Вне тела функции текущая рамка исчезает. Подсказка строки показывает имя функции
и её область видимости, если она указана парсером.

Для рамок используются определения парсера и лексический разбор тела. Поддержаны
C, C++, C#, Java, JavaScript и TypeScript с телами в фигурных скобках; прототипы,
незавершённые тела и выражения без тела в скобках не получают рамку. Скобки в
комментариях и строках исключаются из разбора. Это лексические границы, без
семантического разрешения шаблонов и препроцессора.

Разбор выполняется в фоне для файлов до 2 МиБ. После изменения текста прежние
рамки снимаются; актуальные появляются после обновления символов. Быстрая смена
текста или закрытие файла отменяет старый результат. Оба режима сохраняются
между запусками.

## Шаблоны кода

**Инструменты → Шаблоны кода / фрагменты…** или кнопка с листом и синими угловыми
скобками на главной панели открывает вкладку Clips. Кнопки содержат только значки;
названия действий появляются в подсказках.

1. Нажмите **Новый шаблон кода**, задайте имя и текст, сохраните.
2. Выберите фрагмент; при необходимости выделите текст в редакторе.
3. Нажмите **Вставить как шаблон кода — подставить переменные** (лист со скобками).
4. Введите значения пользовательских параметров и нажмите **Вставить**.

Пример шаблона:

```c
// $date$ — $filename$
void $name$(void)
{
    $selection$$cursor$
}
```

`$date$` — местная дата `YYYY-MM-DD`, `$time$` — время `HH:MM:SS`, `$file$` — полный
путь, `$filename$` — имя файла, `$project$` — имя проекта, `$selection$` — выделение,
`$cursor$` — конечная позиция курсора. Для безымянного файла/отсутствующего проекта
соответствующая переменная пуста. Все остальные переменные вида `$identifier$`
запрашиваются в диалоге; повторения получают одинаковое значение. Имена учитывают
регистр и используют латинские буквы, цифры и подчёркивание, начиная с буквы или `_`.
`$$` даёт буквальный доллар; `$$date$$` даёт текст `$date$`.

Значения не разворачиваются повторно, поэтому выделенный код с `$name$` сохраняет
его буквально. Первый `$cursor$` задаёт позицию курсора; последующие удаляются.
Если маркера нет, курсор оказывается в конце вставки. Вставка заменяет одно обычное
выделение, сохраняет формат окончания строк файла и отменяется одним Undo; Redo
возвращает вставленный текст. Отмена ввода параметров не меняет файл. Если источник,
выделение, режим окончания строк или активный файл изменился во время диалога,
вставка отклоняется и её нужно повторить.

Обычная кнопка **Вставить** и двойной клик на Clips вставляют буквальный текст.
Шаблоны хранятся вместе с Clips в `config/insight/notes.conf`; редактирование,
переименование, импорт и экспорт выполняются существующими кнопками Clips.
Дубликат имени при создании отклоняется. Пределы: 64 КиБ текста шаблона/значения,
64 уникальные переменные, 256 КиБ развёрнутого текста; общая база — до 64 записей.
Языковые ограничения шаблонов и их участие в автодополнении пока не добавлены.
