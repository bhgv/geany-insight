# Перечитать изменённые файлы

**Файл → Перечитать изменённые файлы…** проверяет время изменения до 128 открытых сохранённых локальных файлов. Команда не перечитывает состав проекта и не перестраивает индекс. Ей можно назначить сочетание в группе **Document**; она также доступна в браузере команд.

В списке видны пути и состояния: без изменений на диске, изменён извне, изменён извне с несохранёнными правками буфера, недоступен или не поддерживается. Автоматически отмечаются только изменённые файлы без несохранённых правок. Флажки выбирают пакет для перечитывания, выделенная строка — файл для **Открыть файл** и **Сравнить с диском**. Есть команды **Выбрать без правок**, **Снять выбор**, **Копировать пути** и **Обновить**. «Открыть файл» закрывает список и активирует выбранную вкладку исходника. Обновление создаёт новый снимок и сбрасывает флажки. Постоянного опроса и таймера автоматического перечитывания нет.

**Перечитать выбранные…** всегда запрашивает подтверждение и сообщает число буферов с несохранёнными правками. Содержимое буфера заменяется содержимым диска; записи файлов не происходит. История Undo, обработка кодировки, восстановление курсора и режим чтения следуют штатному механизму Geany и его настройкам. Буферы только для чтения тоже можно перечитывать. Отмена сохраняет их содержимое. Это вариант команды Source Insight [Reload Modified Files](https://www.sourceinsight.com/doc/v4/userguide/Manual/Command_Reference/Reload_Modified_Files.htm) с предварительным просмотром списка; настройка Sharing для каждого файла не добавляется.

Перед первым перечитыванием проверяется весь выбранный пакет. Перед каждым следующим — ID документа, путь, хеш буфера, позиция истории правок, кодировка, BOM, режим чтения и метаданные/идентичность файла на диске. Закрытие, переименование, правка буфера или внешнее изменение останавливают пакет и обновляют список. Уже завершённые перечитывания остаются выполненными; общего отката и блокировки файловой системы нет. Между файлами могут выполняться штатные обработчики перечитывания.

Проверка времени специально не сравнивает побайтно каждый файл на диске. Изменения с неразличимым временем и без штатного уведомления могут быть пропущены. Файлы более 8 МиБ, удалённые, несохранённые и не обычные файлы не включаются в пакет. Проверка буферов ограничена 8 МиБ на файл и 64 МиБ за проход. Число пропущенных файлов показывается. Фоновое чтение всего проекта не добавляется.

**Сравнить с диском** открывает существующее сравнение снимков только для чтения для выделенной доступной строки, без применения и сохранения. Действуют прежние ограничения: UTF-8 без NUL, до 1 МиБ на сторону; само штатное перечитывание использует кодировку документа. Закройте сравнение для возврата к списку. Для устаревших снимков нажмите «Обновить».
