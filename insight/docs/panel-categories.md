# Categories

An overview of symbols by index category.

## Controls

Expand groups and filter entries. A Ctags kind letter depends on the language; this view is separate from the optional grouping in symbol panels.

## Short tutorial

Expand a category, select a symbol for preview and double-click to open it.

The ? button at the upper right opens this page. Help follows the interface language selected in Options.
