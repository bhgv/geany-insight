# Lua API 0.7

`INSIGHT_API_VERSION` — строка `"0.7"`. Возможности конкретного host проверяются
через `editor.has(name)` внутри команды. Во время загрузки документа нет, поэтому
has возвращает false для операций над документом; has("has") всегда true.

## Команды и горячие клавиши

Одноразовые скрипты запускаются через Tools → Insight: Run Lua script… в новом
Lua-состоянии. Расширение загружается через Insight: Lua commands → Load extension…:

```lua
commands.register("selection.wrap", "Wrap selection", function()
    editor.replace_selection("(" .. editor.selection() .. ")")
end, "<Primary><Alt>w")
```

Четвёртый аргумент — необязательная строка GTK accelerator, до 63 байт.
Primary означает основной модификатор платформы. Неверные сочетания и повторное
использование одного сочетания внутри расширения не назначаются. Сочетания не
интегрированы в настройки клавиатуры Geany; конфликты с другими плагинами/Geany
нужно проверять в GUI. Primary+Shift+P зарезервирован для палитры команд.

Command palette ищет по названию и ID, без учёта регистра. Enter запускает выбранную
команду. Можно использовать меню при отсутствии подходящей горячей клавиши.

ID: 1–63 ASCII-символа, сначала латинская буква, затем буквы, цифры, `_`, `.`, `-`.
Название — 1–255 байт без NUL, предпочтительно UTF-8. При некорректном UTF-8 меню
показывает ID. До 128 команд. Повторные ID и регистрация из callback отклоняются.

Переменные и замыкания сохраняются между вызовами, но не после перезапуска.
Успешная загрузка заменяет расширение; ошибка Lua или записи настроек сохраняет
старую сессию. Путь запоминается для автозагрузки; Reload saved extension перечитывает
файл, Unload extension отключает автозагрузку. Выгрузка плагина не стирает выбор.
Во время исполнения команды заменить/перезагрузить расширение нельзя.

Настройки: <configdir>/plugins/insight/extension.conf, версия формата 1, путь в base64
(кодировка, не шифрование). До 32 KiB настроек, 16 KiB пути, 256 KiB Lua-файла.
Принимаются обычные локальные файлы. Автозагрузка только регистрирует функции:
editor/project недоступны при загрузке. Несколько модулей пока не поддерживаются.

## Документ и редактирование

Позиции — **байтовые смещения UTF-8 с нуля**, строки — **с единицы**.

| Метод | Назначение |
|---|---|
| `editor.text()` | Полный текст документа |
| `editor.selection()` | Текст выделения или пустая строка |
| `editor.replace_selection(text)` | Заменить выделение / вставить в позицию курсора |
| `editor.position()` | Позиция курсора в байтах |
| `editor.goto_line(line)` | Перейти к строке с записью в историю Geany |
| `editor.filename()` | Имя файла UTF-8 или nil для безымянного документа |
| `editor.open(path)` | Открыть абсолютный путь; следующие операции используют открытый документ |
| `editor.save()` | Сохранить именованный документ; безымянный нужно сначала сохранить через интерфейс |
| `editor.selection_range()` | Возвращает start, end; end не включается |
| `editor.set_selection(start, end)` | Установить выделение на границах UTF-8 |
| `editor.line_count()` | Число строк, включая пустую последнюю строку |
| `editor.line_text(line)` | Строка вместе с её переводом строки, если он есть |
| `editor.replace_range(start, end, text)` | Заменить диапазон без временного изменения выделения |
| `editor.insert(position, text)` | Вставить текст в заданной позиции |
| `editor.message(text)` | Показать сообщение в строке состояния, до 4096 байт |
| `editor.has(name)` | Проверить доступность метода, включая ограничения read-only |

На Android сейчас доступны text/selection/replace_selection/has; дополнительные
методы пока не подключены к frontend. Неподдерживаемый метод сообщает об ошибке.

NUL в текстовых аргументах запрещён. set_selection/replace_range/insert проверяют
границы диапазона, а настольный host — границы UTF-8. Новые вставки диапазона должны
быть UTF-8. Старый replace_selection на desktop ещё не проверяет валидность UTF-8.
`string.upper` не выполняет Unicode case folding.

Изменения одного вызова группируются в Undo. При editor.open группировка продолжает
работу в новом документе; возврат к предыдущему документу создаёт новую группу.
Ошибки не откатывают уже сделанные правки и переменные Lua. Android одноразовые
скрипты выполняет на копии документа: ошибка не меняет текст UI.

Отсутствие io/os не ограничивает файловые операции, предоставленные editor.open/save.

## События

```lua
events.on("document_save", function(event)
    if editor.has("message") then
        editor.message("Saved: " .. event.path)
    end
end)
```

Поддерживаются document_open, document_save, document_activate, document_close
(перед закрытием). event содержит name и path, path пустой для безымянного документа.
editor обращается к документу события, который может отличаться от активной вкладки.

Обработчики регистрируются только при загрузке, до 32 на расширение. Выполняются
по порядку; ошибка одного не препятствует остальным. Каждый получает отдельный
бюджет инструкций. Документ в обработчике read-only: можно читать текст и показывать
сообщения, но нельзя править, перемещать курсор, открывать или сохранять документы.
Уведомления, возникшие во время исполнения Lua-команды/обработчика, пропускаются,
а не ставятся в очередь. Это предотвращает рекурсию; полная доставка не гарантирована.
События Android пока не подключены.

## Проект и навигация

`project.symbols(prefix, exact)` возвращает до 256 записей и полное число совпадений.
Поля: name, path, scope, kind, line. exact=true включает точное имя, поиск
регистрозависимый. Данные копируются в Lua и могут устареть при хранении.

`project.stats()` возвращает symbols и files_with_symbols: число символов и число
путей с хотя бы одним символом, включая теги открытых документов. Это не общее
число файлов проекта. Индекс является снимком на начало вызова.

Find identifier under cursor выполняет лексический поиск имени по тегам: один
результат открывается, несколько показываются в поиске. Семантического разрешения
перегрузок/namespace и поиска использований пока нет.

Поиск фильтруется по точному имени/префиксу, подстроке scope и точному kind-letter.
Столбцы сортируются; Up/Down выбирают результат, Enter открывает его, Escape закрывает
диалог. Первые 500 результатов. Контекст — до пяти соседних строк с каждой стороны,
выделенная целевая строка и центрирование. Предпочитается открытый, в том числе
несохранённый, буфер; иначе читается файл. До 2 MiB входа и 64 KiB контекста.
Это обычный текст без подсветки синтаксиса. Номера тегов могут отставать от буфера.

## Лимиты и диагностика

Около миллиона Lua-инструкций на загрузку, команду или отдельный обработчик события.
16 MiB Lua-памяти на всю жизнь расширения; C-host, документы и временные данные
статистики не входят в этот лимит. C-функции не прерываются instruction hooks.
Синхронные операции могут задержать интерфейс. Это не строгая песочница.

Доступны base, string, table, math, utf8. Нет io/os/package/debug/coroutine,
load/loadfile/dofile, print, collectgarbage, pcall/xpcall. Метатаблицы доступны,
но __gc запрещён: Lua отключает instruction hooks внутри финализаторов.

Ошибки исполнения содержат Lua traceback; при исчерпании памяти построение
traceback тоже может завершиться ошибкой. Строка состояния ограничивает сообщение
512 байтами. C-сессия однопоточная; её нельзя уничтожать во время исполнения.

### Поиск употреблений в буфере

`local matches, total = editor.occurrences(name, limit)` ищет целый идентификатор
в текущем тексте, включая несохранённые изменения. `limit` по умолчанию 1000,
допустимый диапазон 1–10000. Возвращает таблицу совпадений и полное число.
Поля: `start`, `finish` — полуоткрытый диапазон байтов с нуля; `line` —
строка с единицы; `column` — байтовая колонка с нуля. Поддерживаются CR, LF, CRLF.
Буфер ограничен 2 МиБ, имя — 1024 байтами. Доступность проверяется через
`editor.has("occurrences")`. Поиск лексический: комментарии и строки включены,
разрешения области видимости нет; это не семантический поиск ссылок.

### Страницы употреблений

`editor.occurrences(name, limit, offset)` поддерживает необязательный `offset`
(по умолчанию 0): число совпадений, пропускаемых до заполнения таблицы.
`total` всегда сообщает число совпадений во всём буфере. Отрицательный offset
отклоняется; offset за пределами результата возвращает пустую таблицу.
Каждый вызов перечитывает буфер: после правки последовательность страниц может
измениться. Название и текст должны быть корректным UTF-8 без NUL.

`project.files(prefix, limit, offset)` возвращает таблицу уникальных путей и
полное число. Значения по умолчанию: пустой prefix, limit=256, offset=0; limit
до 1024. Включены только файлы с индексированными символами.
