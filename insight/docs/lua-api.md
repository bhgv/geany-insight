# Lua API 0.5

`INSIGHT_API_VERSION` содержит строку `"0.5"`.

## Одноразовый скрипт

Tools → Insight: Run Lua script… выбирает файл и запускает его в новом состоянии
Lua. Глобальные переменные между такими запусками не сохраняются. Файл — до 256 KiB.

```lua
editor.replace_selection("(" .. editor.selection() .. ")")
```

## Расширение с командами

Tools → Insight: Lua commands → Load extension… загружает один Lua-файл.
Успешная загрузка заменяет прежнее расширение и его состояние. Ошибка загрузки
оставляет прежнее расширение, команды и переменные без изменений.

```lua
local calls = 0
commands.register("selection.number", "Insert next number", function()
    calls = calls + 1
    editor.replace_selection(tostring(calls))
end)
```

Зарегистрированная команда появляется в меню Insight: Lua commands.
Команды доступны при открытом документе и всегда работают с текущим документом.
Глобальные переменные и замыкания расширения сохраняются между вызовами.
После успешного выбора файла его путь сохраняется для автозагрузки при следующем
включении плагина или запуске Geany. Сам текст скрипта и состояние Lua не сохраняются:
файл перечитывается, глобальные переменные и замыкания создаются заново.
Reload saved extension перечитывает сохранённый файл без системного диалога.
Если загрузка или запись настроек не удаётся, прежние команды и их состояние
остаются рабочими. Ошибка автозагрузки видна в строке состояния; её настройки
не стираются, поэтому можно исправить файл и повторить загрузку.

Unload extension удаляет команды и состояние и отключает последующую автозагрузку.
Выгрузка самого плагина не стирает выбранный файл. Несколько модулей и горячие
клавиши пока не добавлены. Перезагрузка/замена/выгрузка во время исполнения команды
отклоняется, чтобы не уничтожить используемое Lua-состояние.

Настройка: <configdir>/plugins/insight/extension.conf. Формат имеет версию 1 и
содержит абсолютный путь в base64; base64 здесь только кодировка, не шифрование.
Файл настройки ограничен 32 KiB, путь — 16 KiB, Lua-файл — 256 KiB. Принимаются
обычные локальные файлы. Настройки пути относятся к текущей ОС и не предназначены
для переноса между компьютерами. Во время загрузки editor/project API по-прежнему
недоступен: доступ появляется только при явном вызове команды.

`commands.register(id, label, callback)` разрешён только во время загрузки:

* id: 1–63 ASCII-символа; первый символ — латинская буква, затем буквы, цифры, `_`, `.`, `-`.
* label: непустая строка до 255 байт без NUL; рекомендуемый формат UTF-8.
  Если label не является UTF-8, настольный интерфейс показывает id.
* callback: функция без аргументов. Повторные id отклоняются.
* Не более 128 команд в расширении.

Во время загрузки расширения editor/project API недоступен: функция загрузки
только регистрирует команды. В callback API доступен. Регистрация новых команд
из callback отклоняется. Примеры: examples/commands.lua.

## Документ

| Функция | Результат |
|---|---|
| `editor.text()` | Текст текущего документа, строка UTF-8 |
| `editor.selection()` | Текст выделения; пустая строка, если выделения нет |
| `editor.replace_selection(text)` | Заменяет выделение или вставляет текст в позиции курсора |

NUL в заменяемом тексте отклоняется. На Android также проверяется корректность UTF-8.
`string.upper` не обеспечивает Unicode case folding; пример uppercase предназначен для ASCII.

В Geany изменения одного скрипта/команды объединяются в одну операцию Undo.
Если callback падает после изменения документа, уже сделанные изменения остаются
и отменяются через Undo. Состояние Lua после ошибки тоже не откатывается.
Android пока использует только одноразовый запуск на копии документа: ошибка не
изменяет текст UI. Меню именованных команд Android ещё не подключено.

## Символы проекта

```lua
local matches, total = project.symbols("insight_")
local exact, count = project.symbols("insight_run", true)
```

Первый результат — таблица до 256 записей; второй — полное число совпадений.
Поля записи: name, path, scope, kind, line. Строки начинаются с 1.
По умолчанию поиск по префиксу, второй аргумент true включает точное имя.
Поиск регистрозависимый. Данные копируются в Lua, результат можно сохранять между
вызовами, но он становится снимком и может устареть. API не ищет использования.
На Android проектный индекс пока не подключён.

## Лимиты и ошибки

На загрузку и каждый вызов команды устанавливается новый бюджет около миллиона
Lua-инструкций. Лимит Lua-памяти 16 MiB общий для всей жизни расширения, включая
сохранённые переменные; для одноразового скрипта действует на один запуск.
C-функции библиотек и host callbacks не прерываются счётчиком инструкций.
Это ограниченный локальный API, не строгая песочница.

Доступны base, string, table, math, utf8. Нет io/os/package/debug/coroutine,
load/loadfile/dofile, print, collectgarbage, pcall/xpcall. Метатаблицы доступны,
но `__gc`-финализаторы запрещены: Lua выключает instruction hooks внутри них.

Ошибки видны в строке состояния Geany. Traceback, события редактора и фоновое
выполнение команд пока не реализованы. C API сессии однопоточный; host callbacks
не должны уничтожать сессию во время исполнения. Вложенный load/invoke отклоняется.
