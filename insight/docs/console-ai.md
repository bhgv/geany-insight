# ИИ-помощник консоли

Откройте **AI Assistant…** на панели SSH shell или в контекстном меню обычного Terminal. **Tools → Console AI Assistant…** открывает пустой контекст для вставки сообщений. Нужен Python 3: сетевой помощник использует стандартную библиотеку без SDK.

![Помощь с консолью и проверка исправлений](media/console-ai.svg)

## Подключение API

Выберите OpenAI / ChatGPT API, xAI / Grok, DeepSeek, Qwen / Model Studio либо совместимый API. Укажите **ID модели из своего API-аккаунта**, ключ, полный адрес chat/completions и исполняемый файл Python 3. Подписка веб-ChatGPT сама по себе не настраивает API-доступ.

| Провайдер | Адрес / настройка | Переменная ключа |
| --- | --- | --- |
| OpenAI | `https://api.openai.com/v1/chat/completions` | `OPENAI_API_KEY` |
| xAI | `https://api.x.ai/v1/chat/completions` | `XAI_API_KEY` |
| DeepSeek | `https://api.deepseek.com/chat/completions` | `DEEPSEEK_API_KEY` |
| Qwen | Замените `YOUR_WORKSPACE` и регион в шаблоне адресом своего workspace Model Studio | `DASHSCOPE_API_KEY` |
| Custom | Полный совместимый адрес; HTTP разрешён только на loopback | ввод вручную |

При смене провайдера обновляются адрес и ключ из соответствующей переменной окружения. Название модели редактируется свободно. В `insight-ai.conf` сохраняются только провайдер, адрес, модель и Python. Ключ остаётся в памяти и передаётся помощнику через stdin, без аргументов командной строки. Помощник не сохраняет вывод, код и историю беседы. Для удалённых API требуется HTTPS; перенаправления отклоняются. Обычные настройки сессии редактора и оболочки продолжают действовать.

## Вопросы о сообщениях и коде

1. Кнопка SSH берёт выделенный вывод либо последние 16 000 символов. Меню Terminal берёт выделение, если установленный VTE это поддерживает, иначе видимый вывод. Просмотрите и отредактируйте контекст: открытие окна ничего не отправляет.
2. Для связи ошибки с кодом выберите документ и нажмите **Attach current file**. Будут приложены полный текущий UTF-8 буфер, включая несохранённые изменения, и путь файла. **View attached code** показывает именно этот снимок. Приложение явно запрашивается пользователем; предел — 128 КиБ, поддерживается пустой файл. Другие файлы проекта автоматически не читаются.
3. Введите вопрос о команде, настройке, ошибке или её связи с кодом и нажмите **Send**. Передаются показанный контекст, приложенный снимок/путь, вопрос и история объяснений из памяти. Контекст ограничен 64 КиБ. Новое приложение файла и **Detach code / clear history** сбрасывают беседу; история также сбрасывается при превышении 64 КиБ.
4. Ответ может содержать объяснение, однострочную команду и полный вариант замены приложенного буфера. Обычный текст показывается без предложения правки. Неполные/обрезанные ответы отклоняются. **Cancel request** завершает сетевой помощник; закрытие окна также отменяет запрос. Сетевой тайм-аут — 60 секунд.

**Insert suggested command (do not run)** вставляет команду в строку SSH либо в чистую командную строку локального терминала без Enter. Подключение SSH и выполнение не запускаются. Если в локальной строке уже есть команда, вставка отклоняется. Проверьте предложение и запускайте самостоятельно.

## Исправления через Diff / Merge

**Review code in Diff / Merge** открывает существующее окно сравнения: слева захваченный исходник, справа предложение, в Result редактируемый результат. Область объяснения показывает ответ модели; соседнее поле вопроса и **Ask about this change** явно отправляют дополнительный запрос через помощника.

Выберите изменения через **Take Right**, **All Right** либо вручную отредактируйте Result. **Apply Result to Source** переносит результат в исходный редактор одним действием Undo. Проверяются идентификатор документа, имя, точное совпадение содержимого со снимком и возможность записи. Если документ изменён, закрыт, переименован или доступен только для чтения, применение отклоняется: приложите свежий код и запросите новое предложение. Result ограничен теми же 128 КиБ UTF-8. Применение не сохраняет файл и не отправляет его по SSH: после проверки используйте обычное сохранение / загрузку удалённого файла.

Обрабатывается один приложенный буфер за раз. Автоматический поиск по проекту, запуск инструментов модели и многофайловые патчи пока не реализованы. Дополнительные вопросы используют старый снимок до повторного приложения. Предложение модели может потребовать исправления.

## Проверка

Транспорт проверяется локальным mock API: совместимые запросы четырёх провайдеров, авторизация, некорректные и обрезанные ответы, перенаправления, ограничения размеров и управляющие символы команд. Нативный тест Linux проходит через реальные виджеты SSH, помощника и Diff: приложение кода, дополнительные вопросы, вставка без выполнения, защита изменённого/readonly буфера, один Undo, неизменный файл на диске, отмена и меню локального VTE. Ключи живых API не предоставлялись; реальные аккаунты OpenAI/xAI/DeepSeek/Qwen, Windows и Android не проверялись.

Документация API: [OpenAI](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create), [xAI](https://docs.x.ai/developers/model-capabilities/legacy/chat-completions), [DeepSeek](https://api-docs.deepseek.com/), [Qwen](https://www.alibabacloud.com/help/en/model-studio/qwen-api-via-openai-chat-completions).


В режиме проверки ИИ **More comparison tools** разворачивает строки файлов, пробельных символов, регулярных выражений и замены; Ctrl+H также раскрывает инструменты замены. По умолчанию они свёрнуты, чтобы оставить место исходникам и Result. Номера строк включены.

## Встроенная SSH-консоль, вложения и история

Ai открывается внутри выбранного SSH-терминала. Настройки сгруппированы сверху в Connection, Context / source, Attachments. Скрепка принимает до четырёх файлов суммарно 512 КиБ: тексты отправляются как текст, PNG/JPEG/WebP/GIF — как изображения, PDF и прочие бинарные типы — как file parts при поддержке API/моделью. ZIP/TAR/GZ разбираются в памяти: отправляется список и небольшие UTF-8 файлы, бинарные или крупные участники обозначаются как неотправленные. Лимиты: 64 записи, 512 КиБ содержимого, 64 КиБ на текстовый файл; tar-поток с заголовками — до 1 МиБ. На диск архивы не распаковываются.

Возвращённые моделью файлы (до четырёх, до 256 КиБ суммарно и в пределах общего ответа) доступны в Attachments → Save received file. Сохраняются только реальные проверенные байты из ответа, по выбранному пользователем пути; запуска и автоматического открытия нет. Поддержка изображений и бинарных file parts зависит от API и модели; ошибка провайдера показывается.

Список над ответом хранит до 32 ответов этого сеанса. Переключение возвращает текст, команду и файлы; исходник для Diff остаётся тем же явно приложенным снимком. Повторное приложение/отключение исходника очищает историю ответов. Команда Run reviewed command в SSH запускает выбранное предложение только по нажатию. Кнопка перехода рядом с вводом терминала открывает выбранную диагностику file:line в существующем локальном исходнике или кэше SFTP.

Во встроенном режиме блок AI settings / context / attachments свёрнут, чтобы ответ и промпт помещались в невысокой панели. Разверните его для настройки подключения, просмотра контекста или скрепки.
