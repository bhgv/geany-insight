# Типы файлов

Файлы manifest проекта, сгруппированные по действующему языковому профилю. У открытого файла учитываются его parser/filetype и forced binding; у закрытого — сохранённый профиль пути/расширения. Это не только группировка по расширению. Предел дерева — первые 10000 файлов manifest.

## Управление

Фильтр принимает фрагменты полного пути, glob (`*.cpp`), regex с начальным `?` и нечёткие подпоследовательности (`~fced.special`). Пустые группы скрываются, группы совпадений раскрываются. Счётчик показывает показанные файлы / manifest. Неверный regex отмечается и сохраняет последний корректный результат; Enter при ошибке ничего не открывает.

Выбор файла показывает Context; Enter/двойной клик открывает файл. Группа раскрывается/сворачивается без перехода редактора. Правый клик выбирает строку без изменения Context/редактора и открывает меню. Для группы или пустого результата исходные команды недоступны.

Меню: открыть исходник, копировать имя/путь, создать точный фильтр выбранного файла, очистить запрос, раскрыть/свернуть ветку или все группы, выбрать видимые колонки, сбросить колонки, открыть справку. Колонка имени обязательна. Перестановка, ширины, видимость и сортировка сохраняются независимо от Categories и других списков. Сброс колонок сохраняет сортировку и запрос.

В дереве: Ctrl+F — фильтр, Ctrl+C — имя, Ctrl+Shift+C — путь, Ctrl+Enter — открытие, Menu/Shift+F10 — меню, Escape — редактор. В фильтре Down выбирает первый файл, Enter открывает его, Escape очищает запрос перед возвратом фокуса. На macOS используется Primary. При обновлении сохраняются подходящая выбранная запись и раскрытые группы.

## Короткий урок

1. Откройте проект и «Типы файлов»: собственные профили будут отдельными группами.
2. Введите `*.cpp` или нечёткий путь и проверьте счётчик.
3. Правым кликом скопируйте путь или включите точный фильтр.
4. Настройте колонки, перезапустите редактор и проверьте восстановление.
5. Очистите запрос и откройте файл через Down, затем Ctrl+Enter.

Настройки языков: [languages.md](languages.md). Кнопка «?» открывает эту страницу на языке интерфейса.
