Блок 1: native-тест воспроизвёл пропущенные объявления `name: Type`. После исправления проходят объявления модуля, класса, локального имени и поля `self`. GUI проверяет F12 и Follow для трёх вариантов; это навигация к аннотации, без исполнения Python и без заявления о создании значения.

Блок 2: первый формальный параметр непосредственного метода работает с любым именем; ordinary-функции и не-первые параметры не становятся получателями. `builtins.staticmethod` и стеки с многострочными декораторами подавляют неявный экземпляр. Native и общий F12/Follow GUI проходят.

Блок 3: воспроизведены отсутствующие владельцы `Class().field` и `factory().field`. Однозначные локальные классы и простые объявленные типы результата поддержаны; неизвестные/async-результаты и затенённые классы отклоняются. Native и F12/Follow GUI проходят.

Блок 4: воспроизведены пропущенные составные импорты. Поддержаны несколько `import pkg.mod` с общим корнем, `pkg.mod.func`, `pkg.mod.Class.field` и `alias.Class.field`. Выбирается самый длинный явно импортированный префикс; отсутствующие импорты не открываются по случайному пути. Native и F12/Follow GUI проходят.

Блок 5: поля импортированных классов разрешаются через простые аннотации переменных/параметров, единственное присваивание `Alias()` / `mod.Class()` и прямой вызов конструктора. Поиск ограничен файлом импортированного класса. Native и F12/Follow GUI проходят; аннотация параметра разрешается снаружи тела функции.
