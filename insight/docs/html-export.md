# Экспорт кода в HTML с оформлением

**Файл → Экспорт файла в HTML…** фиксирует текущий декодированный буфер, включая несохранённые правки. **Экспорт выделения в HTML…** берёт одно непустое обычное выделение, в том числе обратное. Прямоугольные, множественные выделения, виртуальные пробелы, разрезанные символы UTF-8 и пары CRLF не поддерживаются. Экспорт доступен и для исходника только для чтения. Обе команды имеют изначально неназначенные сочетания Editor и видны в браузере команд.

![Экспорт HTML с оформлением в работающем GTK-редакторе](media/html-export.jpg)

В окне есть **Снимок кода** — Scintilla только для чтения с захваченным оформлением — и **Исходный HTML**, где показано до 32 КиБ сформированной разметки. Предпросмотр кода нумерует собственные локальные строки; HTML использует исходные номера строк, в том числе при частичном выделении. Флажок **Номера строк** управляет полем номеров в экспорте. Его изменение очищает результат; **Сформировать** пересчитывает тот же снимок. Для более позднего текста закройте и снова вызовите команду. Предпросмотр не является встроенным браузером.

Из активных стилей редактора захватываются цвета текста и фона, семейства шрифтов, целые размеры в пунктах, жирность, курсив и подчёркивание. Табуляция использует захваченную ширину. Самостоятельный HTML5 содержит встроенный CSS и не требует внешних таблиц стилей, шрифтов, изображений или скриптов; при отсутствии указанного шрифта используется установленный моноширинный. Пользовательский шрифт всё равно должен быть установлен на машине просмотра. Размеры и табуляция ограничены 1–100 пунктами и 1–32 колонками. Масштаб, сворачивание, выделение, индикаторы, семантические ссылки, преобразование регистра и дробные размеры шрифтов не экспортируются. Межстрочный интервал браузера может отличаться.

![Схема экспорта оформленного HTML](media/html-export.svg)

**Копировать HTML** копирует полный документ обычным текстом. **Открыть исходный HTML** создаёт отдельную редактируемую несохранённую вкладку с уникальным именем; браузер не запускается, HTML не исполняется. **Сохранить…** предлагает `<исходник>.html`, подтверждает замену существующего обычного файла и пишет UTF-8 без BOM. Захваченный исходник, пути и идентичности открытых документов и файл текущего проекта защищены от замены. Назначения-ссылки и ссылки среди родительских каталогов отклоняются. Текст, имя, признак изменений, выделение и Undo исходника сохраняются. Эти проверки не являются блокировкой файловой системы.

Исходный текст, заголовок и имена шрифтов CSS экранируются для своих контекстов. Идентификаторы остаются текстом, ссылки на определения не создаются. HTML содержит ограничительную Content Security Policy и не содержит исполняемого содержимого. CRLF/CR становятся LF; для строк создаются якоря `L<номер>`. Последний перевод строки оставляет последнюю пустую строку, как в Scintilla. Это оформленное представление, а не побайтовая резервная копия исходника.

Пределы: 1 МиБ захваченного текста и 8 МиБ HTML. Нужен UTF-8 без NUL; управляющие символы C0 кроме табуляции, CR и LF отклоняются. Частая смена стиля может превысить предел HTML даже при меньшем исходнике. Генерация выполняется отменяемой фоновой задачей; ошибка или отмена не разрешает копирование, открытие и сохранение, а закрытие отменяет незавершённую работу. Настройки не сохраняются. Экспортируется один снимок файла или выделения; HTML всего проекта, внешний CSS, ссылки на символы и оглавление здесь пока не реализованы.

Оригинальная команда Source Insight: [Export File as HTML](https://www.sourceinsight.com/doc/v4/userguide/Manual/Command_Reference/Export_File_as_HTML.htm). Экспорт выделения и это окно предпросмотра — расширения Geany Insight. См. [Отчёты по проекту](project-report.md), [Сохранить выделение / копию](file-text.md).

Проверка: [полная сборка и установка Linux, все 64 теста прошли](https://github.com/bhgv/geany-insight/actions/runs/39579683417), код `43865a3c664b7c6c4b919d3b284560424be69189`; ошибок, пропусков и тайм-аутов нет. Проверены экранирование HTML/заголовка/шрифтов CSS, цвета BGR→RGB, жирность/курсив/подчёркивание, стили на байтовых границах UTF-8, якоря и смешанные окончания строк, отключение номеров, пустой/неверный/NUL/управляющий ввод, отмена, пределы и защита сохранения. GUI полного редактора проверяет обе команды меню/клавиатуры, захват реальных стилей лексера, цветной предпросмотр только для чтения, сброс результата при изменении номеров, полные Copy/Save/Open, неизменность снимка после правок исходника, Undo, номера строк обратного выделения, отказ для пустого/прямоугольного выделения и исходник только для чтения.
