# Полный функциональный перенос Source Insight 4

Цель: функциональность по руководству Source Insight 4, работающая в native Geany Insight. Завершение означает реализованное поведение и проверки, а не наличие кнопки или прототипа. Текущий проект ещё не достиг полного паритета.

Основная проверяемая карта: [source-insight-parity.md](source-insight-parity.md). Доказательства изменений: [progress.md](progress.md). Эталон панелей: [официальное руководство](https://www.sourceinsight.com/doc/v4/userguide/Manual/Window_Tour/Panel_Windows.htm).

## Закрываемые блоки

- [x] File/Project Symbols: запросы, типы, группы, меню/клавиатура, дозагрузка, колонки/сортировка/история.
- [x] Project Folders: фильтр/счётчик, меню, пути, Locate/Follow, ветки и сохранение Follow.
- [x] File Types: действующие профили, фильтр/счётчик, меню/клавиатура, колонки и сортировка.
- [x] Categories: языковые типы, вложенные scope, прямые члены однозначных классов, фильтр, дозагрузка, Info/References, меню/клавиатура и колонки.
- [x] Цветной Context, ссылки, поиск, история, проверка снимка перед переходом.
- [x] Bookmarks/Clips, шаблоны, переменные, языковые привязки, импорт/экспорт.
- [x] Window List, настройки списка и геометрии; пользовательские раскладки A–D.
- [x] Поиск/замена, regex/UTF-8, Boolean keywords, word variations и нечёткие подпоследовательности.
- [x] Основные lexical/tag Relations, один уровень графа, экспорт графа.
- [x] Native Linux/Windows x64 сборка, portable GTK, локальная RU/EN справка.

Эти отметки закрывают описанный объём, а не все особенности соответствующей панели. Ограничения перечислены ниже и в карте паритета.

## Оставшийся обязательный объём

- [ ] Транзитивные Base/Derived, наследуемые члены и безопасное поведение при циклах/неоднозначности.
- [ ] Раскрываемые деревья Relations с историей веток и пределами глубины/размера.
- [ ] Разрешение aliases, полных типов и перегрузок; семантически привязанные ссылки и вызовы.
- [ ] Полная иерархия scope в File/Project Symbols, вложенные типы и семантические владельцы.
- [ ] Browse неиндексированных файлов/каталогов и виртуальные группы проекта.
- [ ] Master File List: автоматическая синхронизация и проверка изменений/исключений.
- [ ] Полная сверка File Type Options, автодобавления файлов и настроек отдельных языков.
- [ ] Перетаскивание и snap-to-edge панелей, docking Window List и сверка всех параметров раскладок.
- [ ] Полные функции/блоки по отступам и end-delimited языкам, структурное выделение и Overview.
- [ ] Переименование с просмотром изменений, проверкой снимков и безопасным применением.
- [ ] Базы шаблонов отдельных проектов, completion и редактируемые placeholders после вставки.
- [ ] Метрики и сведения Symbol Info, выведенные типы и устойчивые кандидаты.
- [ ] Переносимые пути Bookmarks/Clips и файлов проектов.
- [ ] Полное покрытие команд панели/меню/клавиш по руководству и миграция настроек/скриптов.
- [ ] Регрессии GUI Windows x64 для всех перенесённых областей и целевых языков.

Расширения SSH, macOS и Android учитываются отдельно от паритета Windows-продукта. Сборка пользовательских проектов ранее исключена из цели; сборка самого редактора остаётся обязательной.

Нельзя объявлять полный перенос завершённым, пока обязательные пункты остаются открытыми.
