# Полный функциональный перенос Source Insight 4

Цель: функциональность по руководству Source Insight 4, работающая в native Geany Insight. Завершение означает реализованное поведение и проверки, а не наличие кнопки или прототипа. Текущий проект ещё не достиг полного паритета.

Основная проверяемая карта: [source-insight-parity.md](source-insight-parity.md). Доказательства изменений: [progress.md](progress.md). Эталон панелей: [официальное руководство](https://www.sourceinsight.com/doc/v4/userguide/Manual/Window_Tour/Panel_Windows.htm).

## Закрываемые блоки

- [x] File/Project Symbols: запросы, типы, группы, меню/клавиатура, дозагрузка, колонки/сортировка/история.
- [x] Project Folders: фильтр/счётчик, меню, пути, Locate/Follow, ветки и сохранение Follow.
- [x] File Types: действующие профили, фильтр/счётчик, меню/клавиатура, колонки и сортировка.
- [x] Categories: языковые типы, вложенные scope, прямые члены однозначных классов, фильтр, дозагрузка, Info/References, меню/клавиатура и колонки.
- [x] Цветной Context, ссылки, поиск, история, проверка снимка перед переходом; восстановление Follow после обновления без фокуса с неизменившейся кареткой, сохранение ручного отключения без изменения каретки/текста и native GUI.
- [x] Bookmarks/Clips, шаблоны, переменные, языковые привязки, импорт/экспорт.
- [x] Window List, настройки списка и геометрии; пользовательские раскладки A–D.
- [x] Поиск/замена, regex/UTF-8, Boolean keywords, word variations и нечёткие подпоследовательности.
- [x] Основные lexical/tag Relations, один уровень графа, экспорт графа.
- [x] Native Linux/Windows x64 сборка, portable GTK, локальная RU/EN справка.

Эти отметки закрывают описанный объём, а не все особенности соответствующей панели. Ограничения перечислены ниже и в карте паритета.

## Оставшийся обязательный объём

- [x] Транзитивные tag-based Base/Derived и наследуемые члены, пространства имён, циклы/неоднозначность, пределы и проверки. Семантические aliases/перегрузки остаются отдельным обязательным пунктом.
- [x] Раскрываемый tag outline Relations: ленивые Bases/Derived/Members, ветки/Back, циклы, фильтр предков, пределы и native GUI.
- [x] Раскрываемый граф tag Relations: общие ветки outline, реальные родительские связи, +/−/клавиатура, ориентации, zoom/export и проверки.
- [ ] Многоуровневые Calls/References и контекстное разрешение их целей.
- [ ] Разрешение aliases, полных типов и перегрузок; семантически привязанные ссылки и вызовы. Выполнено: scoped nominal lookup и цепочки typedef/using для переходов к членам, с guards/языковой изоляцией и core/native GUI; переходы к унаследованным членам со скрытием имён и nominal-цепочки полей, включая this/static/global receivers; результаты функций/методов с единым nominal-типом, скрытие локальным именем/макросом и профиль парсера независимо от расширения. Параметры шаблонов C++ сохраняются как barriers, исключающие ложную привязку зависимого T к глобальному классу; scope/path/line и native GUI проверены. Templates/overloads/include semantics и полные выражения остаются открытыми.
- [x] Вложенные tag scope в File/Project Symbols, предки фильтрованных символов, независимые настройки и GUI-проверки C++/Python.
- [ ] Семантические владельцы вложенных типов и согласование с aliases/перегрузками. Выполнено: импорт namespace aliases C++ и их целей, прямые вложенные nominal-типы через alias владельца, вложенные aliases и типы результатов функций, declaration scope, фильтрация, циклы/пределы и core/native GUI. Явно квалифицированные наследуемые nested-типы/aliases добавлены с прямым скрытием, неоднозначностью/циклами/границами и core/native GUI. Неквалифицированные nominal-типы ищутся в классах/базах до внешних scope с guards и core/native GUI. Первый компонент квалифицированного имени выбирается до его членов, отсутствующий член не переключает внешнего владельца; повторные namespace объединяются. Для различных функций C/C++/CUDA в одной строке добавлен позиционный cache полных тел с отказом при неоднозначности, core и Context/F12/Follow GUI. Dependent/template, полные позиционные scope/перегрузки и include/ODR/access semantics остаются открытыми.
- [x] Browse неиндексированных файлов/каталогов: отдельный режим Folders, фоновое чтение, навигация/фильтр, preview/open без изменения membership, Unicode/скрытые файлы/пределы/отмена и native GUI.
- [x] Состояние Browse disk: каталог, корректный фильтр, скрытые файлы, режим, ширины/порядок/видимость колонок, проверки повреждённых настроек и native GUI.
- [x] Browse disk: сохранённое слежение за текущим файлом, выбор без перехода/preview, сохранение фильтра и видимость скрытого/усечённого файла, пауза вне режима диска и native GUI.
- [x] Folder Browser Font & Color: независимые шрифт/цвета дерева и дискового списка, настройки/тема/отмена/пределы, сохранение цветов выделения и native GUI.
- [x] Browse disk context menu: правый щелчок без preview/перехода, Menu/Shift+F10, явные preview/open, копирование Unicode-пути/имени, каталог без выбора, Up/Refresh, New folder/Font & Color, guards/RU/native GUI.
