# Отчёт по проекту и экспорт списка файлов

**Проект → Отчёт по проекту…** фиксирует завершённый список файлов и опубликованный индекс символов текущего проекта Geany. Папка, открытая только как рабочая область, проектом не считается. Дождитесь индексации; после отменённого или неудачного обхода его нужно запустить заново. Файлы без символов тоже включаются. Используется индексируемый состав проекта с существующими пределами обхода, а не все файлы на диске.

![Отчёт по проекту в работающем GTK-редакторе](media/project-report.jpg)

Начальный предпросмотр строится в отменяемой фоновой задаче. **Включить символы** добавляет определения под каждым файлом, **Номера строк** — номера строк определений с единицы. **Сортировать по → Порядок в файле / Имя** задаёт порядок внутри файла. **Типы символов…** выбирает точные коды типов из захваченного индекса; пустой выбор исключает все символы. Один код парсера может иметь разный смысл в разных языках. **Относительные пути файлов** отсчитываются от корня проекта; для файлов вне него остаются абсолютные пути. Файлы упорядочены детерминированно, по байтам пути.

Изменение настройки очищает предпросмотр и отключает копирование, открытие и сохранение. Нажмите **Сформировать** для пересчёта. Он использует тот же снимок; для более позднего состояния проекта закройте и снова вызовите команду. Символы открытых буферов соответствуют последнему опубликованному разбору, который может отставать от недавнего набора. В отчёте указаны проект, корень, число файлов и выбранных символов, пропуски индексатора и ограниченность снимка или наблюдения за каталогами.

**Копировать отчёт** копирует полный текст. **Открыть отчёт** создаёт отдельную редактируемую несохранённую вкладку с уникальным именем. **Сохранить…** предлагает `<проект>.RPT` и записывает UTF-8 без BOM; для существующего обычного файла действует подтверждение замены. Защищены исходники, файл захваченного проекта, открытые документы и файл текущего проекта. Назначения-ссылки и ссылки среди родительских каталогов отклоняются. Настройки проекта, исходный текст и Undo не изменяются. Эти проверки не являются межпроцессной блокировкой файловой системы.

![Снимок проекта, отчёт и список файлов](media/project-report.svg)

**Проект → Экспорт списка файлов проекта…** выдаёт тот же захваченный состав по одному имени на строку, без заголовков и символов. Доступны копирование, открытие и сохранение; настройки символов отключены. Относительные пути рассчитаны от корня проекта — при импорте используйте тот же корень. Перед относительным именем с начальным `;` добавляется `./`, чтобы оно не стало комментарием. Имена с переводами строк, `*`, `?` или пробельными символами по краям явно отклоняются. Экспорт создаёт список, но не подключает его как Master File List и не меняет состав проекта.

Пределы: 10000 файлов, 250000 символов индекса, 100000 включённых символов, 128 кодов типов, 4 МиБ текста отчёта и 2 МиБ списка файлов. Предпросмотр только для чтения показывает до 32 КиБ с соблюдением границы UTF-8; копирование, открытие и сохранение используют полный результат. Поля отчёта экранируют обратную косую черту, табуляцию и переводы строк. При ошибке или отмене экспорт недоступен; закрытие отменяет генерацию. Настройки не сохраняются. Экспорта HTML/PDF и семантического переразбора нет.

Обе команды имеют изначально неназначенные сочетания клавиш Editor и видны в браузере команд. См. [Проекты Git и состав файлов](panel-project-git.md), оригинальные команды Source Insight: [Project Report](https://www.sourceinsight.com/doc/v4/userguide/Manual/Command_Reference/Project_Report.htm), [Export Project File List](https://www.sourceinsight.com/doc/v4/userguide/Manual/Command_Reference/Export_Project_File_List.htm).

Проверка: [полная сборка и установка Linux, все 62 теста прошли](https://github.com/bhgv/geany-insight/actions/runs/39571708958), код `1bc39c3b18f643b320fb8245ef61179dedd5f80c`; ошибок, пропусков и тайм-аутов нет. Проверены точные пути, состав символов, файлы без символов, сортировка/типы/номера строк, экранирование, отмена, неверный UTF-8, пределы отчёта и списка MFL 2 МиБ, создание/замена и защита исходников, проекта, открытых файлов и каталогов-ссылок. GUI полного редактора проверяет обе команды меню/клавиатуры, несохранённый исходник, ожидание индекса, настройки и сброс результата, фильтр всех/никаких типов, полные копирование/сохранение/открытие, точный список файлов и сохранность выделения, Undo и диска. JPEG — просмотренный снимок настоящего диалога полного редактора из изолированной Linux-проверки под Xvfb с временным проектом, без EXIF. Windows и Android не запускались.
