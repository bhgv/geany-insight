# Geany symbols

The original Geany symbol list for the current file.

## Controls

Expand the category tree. Its context menu provides native list options. Insight File Symbols provides additional filtering, colors and grouping.

## Short tutorial

Select the Symbols tab, expand functions and select a definition to navigate.

The ? button at the upper right opens this page. Help follows the interface language selected in Options.
