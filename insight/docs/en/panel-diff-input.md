# Comparison inputs

The left and right source versions for internal Diff/Merge.

## Controls

Choose two input files. Highlighting marks differing lines. Input panels are read-only; edit the result in the merge panel. External KDiff3 runs only through a separate optional command.

## Short tutorial

Open Diff/Merge from Tools or the main toolbar, choose two versions and navigate to a difference.

The ? button at the upper right opens this page. Help follows the interface language selected in Options.
