# Quick find in file

Find text in the current editor buffer without opening a separate results list. Open Quick find in file from Search/Replace. Ctrl+F opens Geany’s regular Find dialog.

## Controls

Find contains the query. Enter and Next find the next match; Previous finds the previous one. Match case, Whole word and Regex control matching. The close icon or Escape hides the row. The ? button opens this page.

## Short tutorial

Open Quick find in file, type a name and press Enter. Use Next and Previous to inspect occurrences. Enable Whole word to exclude longer names, then close the row with Escape.
