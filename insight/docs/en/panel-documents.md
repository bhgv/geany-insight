# Open documents

A list of editor buffers.

## Controls

Select a row to activate its document. The context menu provides open-file operations. Window List adds filtering and sorting.

## Short tutorial

Open several files and switch between them through this list. For many files, open Window List.

The ? button at the upper right opens this page. Help follows the interface language selected in Options.

More: [window-list.md](window-list.md).
