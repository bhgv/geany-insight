# Messages

General Geany messages and output from native commands.

## Controls

Scroll the list and navigate through recognized source locations. Insight’s extended search results have a separate panel.

## Short tutorial

Read a message; when it contains a recognized file and line, activate it to navigate.

The ? button at the upper right opens this page. Help follows the interface language selected in Options.
