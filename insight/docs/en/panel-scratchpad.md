# Scratchpad

An auxiliary text area for notes.

## Controls

Type, select, copy and paste text. To keep important text in a separate file, copy it to a document and save it.

## Short tutorial

Write a short note about the current task. Copy a useful fragment to the editor.

The ? button at the upper right opens this page. Help follows the interface language selected in Options.
