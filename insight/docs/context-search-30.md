Блок 1: NBSP и emoji больше не склеивают имена. Поддержаны CJK, кириллица, комбинируемые продолжения, курсор внутри многобайтного символа. Используется воспроизводимая таблица Unicode 15.0 XID; нормализация и семантика языка не выполняются. Старые проверки контекста проходят.

Блок 2: поиск целого имени использует те же XID-границы. Проверены NBSP/emoji-разделители, комбинируемые продолжения, CJK, pagination и сохранение байтовых колонок/CRLF. Emoji и одинокая combining mark отклоняются как запросы. Комментарии/строки по-прежнему входят в текстовый поиск; нормализации нет.

Блок 3: отсутствующая строка, невалидный UTF-8 и NUL не оставляют частичные координаты. Выходы обнуляются при отказе; успешный результат публикуется целиком. Проверены пустой текст, финальная пустая строка, смешанные CR/LF/CRLF и прежние границы радиуса. Тесты document/occurrences не регрессировали.

Блок 4: scanner вызовов не выделяет суффиксы числовых токенов (`123fake()`, `0xdead()`) и не создаёт ссылку из середины имени при произвольном cursor. Unicode-границы согласованы с Context/occurrences; сохранено прежнее расширение `$` для C-подобных профилей. Проверены вложенные вызовы, CJK, combining marks, emoji-разделитель, malformed input и структурное выделение. Это лексический кандидат вызова, не AST.

Блок 5: Diff разделяет CR, LF и CRLF, а не считает CR-файл одной строкой. Две несмежные правки дают два блока; оригинальные байты endings сохраняются при реконструкции. Проверены смешанные endings, CR→CRLF, финальная строка и 3000 детерминированных случайных пар. Ограничение квадратичной работы и обрезка общих краёв по-прежнему проходят.
