# Пример встроенного diff / merge

1. Запустите `Start-Insight.cmd`. Откройте `examples/diff-merge/left.ini`.
2. На панели Context нажмите **Diff / Merge…**.
3. В Left выберите `left.ini`, в Right — `right.ini` из этой папки.
4. Нажмите **Compare**. В списке появятся два блока изменений.
5. Выберите первый блок (host и port), нажмите **Take Right**.
6. Выберите второй блок (features), нажмите **Take Left**.
7. Результат должен совпасть с `expected.ini`: сервер из правого файла,
   настройки features из левого.
8. Нажмите **Undo** / Ctrl+Z: первый изменённый блок вернётся к Left.
   **Redo** / Ctrl+Shift+Z вернёт выбранный Right.
9. Измените вручную `timeout = 30` на `timeout = 60` в Result. Проверьте
   Undo/Redo для этой правки, затем верните 30 и сохраните результат через
   **Save result…** в новый файл.

Во втором блоке можно также выбрать **Take Right**, чтобы проверить замену
`legacy_mode` на `retries`. Исходники при сведении не меняются автоматически.
KDiff3 для этого примера не нужен.
